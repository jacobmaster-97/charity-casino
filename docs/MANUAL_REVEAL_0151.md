# 0.15.1 大小／輪盤結果手動確認

階段：既有遊戲介面修訂。使用者要求搖骰／轉珠動畫出現結果後，必須手動確認才進入派彩小視窗。

## 玩家流程

- 大小／輪盤動畫完成後保留骰子點數或輪盤號碼，不再1.4秒後自動轉入派彩。
- 手機揭曉視窗顯示「確認結果・查看派彩」；平板／電腦沿原桌面結果區顯示同名按鈕。
- 按下才開原派彩小視窗；關閉派彩後仍可用「查看派彩」重開，不會自動再彈。
- 挑戰時間在看結果時繼續；手動暫停、背景及手機直向仍按原規則一起停兩個倒數。
- 五分鐘到時或破產，仍保留結果供手動確認，之後派彩視窗提供「查看挑戰結果」，不提供新一局。

## 實作邊界

`MobileRoundReveal`保留本局是否已確認，即使desktop／mobile版型切換也不重置。1400ms剩餘值僅用骰盅抬起動畫位置，不再決定視窗關閉；確認只改呈現狀態，不修改Game、金額、牌局統計或存檔。

`app.mjs`只有大小／輪盤延後自動派彩與最終結算畫面的呈現，明確點擊才繼續。其他三桌保留現有流程。未改下注、亂數、倍率、五分鐘、自動收尾、破產或派彩模型；真正完成局仍立即結算並保存一次，避免全押／重整造成重複派彩。重新整理沿既有完成局checkpoint恢復，不另存未確認的骰子／輪盤呈現快照。

手機確認視窗另修正既有dice-stage min-height:310px造成的溢出。確認按鈕固定可見，結果stage在很矮的手機可局部滑動；重用原金色按鈕、深綠背景、貼圖及原1.2倍子視窗，沒有新常駐HUD或更換素材。
