# 21點可玩切片0.2.0

使用者要求「製作21點，沿用一體賭枱版」。本輪為既有可玩原型接入第三桌；規則以BLACKJACK.md第57–65題為準，不新增其他旁注或even money。

## 玩家流程

大廳21點入座 → 20秒內選五色／自訂／全押籌碼並點主注區 → 發牌 → 明牌A先選保險，10點牌直接查Blackjack → 每手20秒選要牌／停牌／加倍／分牌／投降 → 莊家按S17行動 → 全局分牌及保險一次結算、判達標／歸零、保存。

一體翠綠枱布、酒紅／暖金外框；上莊家，下玩家及底部操作。各手有獨立籌碼落點，加倍／分牌及保險追加使用同一600ms籌碼飛行；原有混色堆疊及大額籌碼保留。莊家暗牌在正常揭示或合法透視前不輸出牌階／花色標籤。

一般螢幕同時呈現各手；窄版三／四手採2×2；又小又矮的螢幕顯示目前手牌及其他手的摘要／籌碼，全部牌況及每手派彩可從明細查看。換牌選擇用現有牌面按鈕，取代底部一般行動列，提供取消，沒有額外手圖或咪牌步驟。選牌本身不扣券，實際點選一張才扣。

## 規則與資金契約

- 連續六副牌，共312個唯一實體ID。A取不爆牌的最高1／11值；莊家軟17停牌。未分牌且未換牌的起始兩張Blackjack淨3:2；普通勝1:1；普通21不勝過莊家Blackjack。
- 任意起手兩張可加倍，追加同手同額，只補一張停牌；非A分牌手可加倍。相同點值可分（含10＋K），追加同額，最多四手。分A只一次，各補一張停牌，不再分或加倍；所有分牌21都是普通21。
- 明牌A先處理保險，不能先透視暗牌；保險不超原注一半及可用餘額，莊家Blackjack淨賠2:1。明牌10點牌先檢查Blackjack。確認莊家非Blackjack後，原始手尚未要牌／加倍／分牌前可晚投降，退半注。
- 一般主注每次至少$1；資金不足$1可全押。加倍／分牌只能使用未投入資金，不預支未結算派彩、不借款。主注／各手／保險金額全以整數美分保存，原下注＋追加立即扣款。
- 全部手牌結束後才派彩；玩家爆牌之手即使莊家其後爆牌也不派。保本按所有手及保險合計淨虧損退50%一次。最終保本後才判目標／破產，資金因全押暫時變零不提前Game Over。
- 無免費道具，延用購買前資金10%價格及原背包：保本在發牌前；透視在莊家已確認非Blackjack後，實際顯示該張暗牌；換牌在當前手尚未要牌／加倍／停牌時，非分A手可用，換後21只算普通21。整局所有分牌合計最多一件。
- 下注及每次行動20秒。空注超時重開，已用保本不退；行動超時停當前手，保險超時不買。普通要牌之後或輪到新手開始新的20秒；透視不改倒數，換牌的動畫耗時亦從原剩餘行動時間扣減，歸零則換牌動作完成後自動停牌。
- 明確暫停、背景／離線／商店保持既有停表及遮桌；頁面存活時按繼續恢復同局、動畫、剩餘行動時間、牌靴及庫存。無局中持久快照；關閉／重整回最後完成局。

## 本輪工程預設（可依實玩調校）

這些是未指定細節的最小實作選擇，非使用者新增永久規則：

- 剩牌少於104張於下一局重洗，不做燒牌儀式，不在局中重洗。104張保守覆蓋四手最多各21張、莊家17張及一次替換，避免看牌後更換牌靴。
- 每張發牌及揭示約571.43ms，最後一張保留同等時間完成動畫。先玩家、莊明、玩家、莊暗。分牌動作先讓兩手各取得一張，再按手牌順序行動；不自動分牌或加倍。
- 空注超時沒有實際發牌，故不消耗牌靴；已啟用道具照扣。所有手已爆／投降／為自然Blackjack且莊家非Blackjack時，揭暗牌但不做無意義額外補牌。
- 保險允許自訂到美分，最多原主注一半向下取整；最小正額一美分。3:2贏款、半注及50%補償不足一美分皆向下取整，沒有欠款累積。
- 換牌後仍可在符合兩張／未普通行動的資格下加倍、分牌或投降；換成21自動按普通21停牌。換掉的牌進本局棄牌，不回靴，不重置20秒。

## 所有者與保存

Game仍為資金、庫存、計時、牌靴及完成checkpoint唯一所有者。blackjack.mjs提供點數／S17條件／資格／洗牌驗證／純派彩；blackjack-game.mjs的方法載入Game原型，處理明確階段及待播放發牌佇列，不設第二個遊戲時鐘。tick沿用Game統一時間，換牌另保留原行動剩餘值，同步扣除動畫用時。

blackjack-view.mjs重用正式baccaratCard的PNG取格與chipFace，提供一體桌、行動與籌碼容器；board.mjs的ChipFlights以實際手牌DOM落點處理bj-*，大小／百家樂繼續原SVG路徑。UI無權直接派錢或耗用道具。行動與道具按鈕帶當前hand id；點擊前推進倒數若已切至下一手，拒絕舊按鈕，避免上一手超時操作誤用至下一手。

schema1與原保存槽保持，新增可選blackjackShoe={cards,cursor,cycle}。舊檔缺此欄位，首次入座才建立六副牌；baccaratShoe繼續保存，各桌完成局攜帶兩副獨立牌靴。所有分牌及保險完成才增rounds一次及寫checkpoint。保本／透視／換牌延用同名背包，舊檔缺swap仍補0。
