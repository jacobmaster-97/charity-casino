# 0.1.2 隨資金調整的籌碼

使用者指出資金增長後仍需反覆疊加小額籌碼。本輪改為每局開始時按總資金顯示五種合適面額，維持相同數量的主要控制。

| 每局開始資金 | 五種快捷籌碼（美元） |
| --- | --- |
| 100 | 1、5、10、25、100 |
| 1,000 | 10、25、100、500、1,000 |
| 10,000 | 100、500、1,000、5,000、10,000 |
| 1,000,000 | 10,000、50,000、100,000、500,000、1,000,000 |
| 20,000,000 | 100,000、500,000、1,000,000、5,000,000、10,000,000 |

這些級距是本輪實作選擇，可再按遊玩回饋調整，沒有新增最低投注或風險限制。

- 從面額梯級選最高的五種可負擔籌碼；不足五種時保留初始五種，超出可用資金的按鈕停用。
- 使用本局開始資金，下注／清除／切換投注種類時不更換面額；下一局才按最新資金更新。
- 玩家原先選擇的每次下注額保持，即使新一局的五種籌碼換了，也不自動提高下注額；自訂欄持續顯示實際選值。新挑戰或讀檔重設$5及取消全押，避免沿用前次的大額選擇。
- 大額簡寫為千／萬／千萬，按鈕title及無障礙標籤提供完整金額；自訂欄、總下注、可用資金仍為確切數字。
- 自訂金額與全押保留；不足$1可全押原規則不變。金額上限仍由遊戲權威狀態檢查，不超額扣款。
- 桌面一般五欄；窄側欄及380px以下手機為三欄換行，按鈕至少48px寬、72px高。不新增其他常駐HUD。
- 沿用已生成的綠色籌碼圖，並非已產生多種色款；圖片路徑修正保留。

## 驗證

新增六項邏輯檢查：初始與富有級距、全資金範圍的可用性、局內穩定與下一局更新、一次下注十萬元、簡寫與完整金額、保留自訂與低資金全押。另加入模組依賴同版本檢查，避免Safari讀取舊規則模組而缺少新匯出。

瀏覽器腳本已補上透過正常匯入流程載入百萬元存檔、點選十萬元籌碼、保留選值／焦點與新挑戰重置的路徑；當前環境尚未成功執行瀏覽器，不能宣稱該腳本或實機測試通過。
