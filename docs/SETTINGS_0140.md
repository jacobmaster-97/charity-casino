# 三類設定及功能0.14.0

使用者要求實作聲音／存檔與資料／說明與關於，並追加回報問題。本版直接接入原遊戲，更新GitHub Pages；Vercel帳戶授權仍待完成。本次新指示取代0.13.2移除設定備份入口的舊文案要求，不增加未要求的畫面模式、道具商店或付費服務。

## 設定畫面

首頁設定、暫停選單設定及大廳更多的設定共用一個視窗。橫向左分類右內容，直向改頂部分類；頁首與返回鍵固定，只有內容局部捲動。深綠金框配酒紅選中狀態，主要正文16px以上、操作44px以上；用實際viewport及safe-area，不硬寫iPhone邊界。切換分類保留對應捲動，教學展開與回報草稿在重繪保留。

從暫停進入，總倒數及行動倒數繼續停止，退出設定回暫停選單，按繼續才復原；從大廳進入則照計時，截止時收尾並顯示真實結算。背景時兩倒數停止，返回目標改成暫停，不因關設定誤恢復。沒有新增常駐牌桌欄位。鍵盤焦點、Escape、Tab包含輸入／文字區／連結／摘要及局部捲動區。

## 聲音

保留舊靜音key與原五款程序聲效。音量0–100，100%沿原master gain .55；主gain即時套用，獨立key charity-casino-sound-volume-v1保存，不進遊戲存檔或排行榜。未知／無效偏好回100，儲存受限時本次有效並顯示提示。音量0或關閉時試聽不可用，不會因試聽擅自開聲；可用時播放籌碼聲，失敗提供提示。調整不改遊戲RNG、計時、資金或牌局。

## 存檔與資料

新schema2存檔加可選頂層savedAt（實際寫入時的毫秒時間），不升schema，不改profile或金額表示。讀取舊檔不補假時間；舊檔可用但顯示未記錄保存時間。儲存失敗仍顯示上一成功記錄的時間，不能把嘗試時間當成功。時間以本機時區格式顯示，不作排行驗證。

匯出以已保存完成局為準；若最新自動保存失敗，仍可匯出記憶體中的完成局checkpoint。未結算牌局不會寫入備份。匯入先檢查100KB、JSON、schema2／race、完整規則與精確金額、統計、牌靴及可選時間，再顯示姓名／賭本／餘時／保存時間供確認。取消／無效檔／儲存失敗不改目前挑戰；確認後先成功保存，才載入，原主存檔保留於既有-backup鍵。讀檔保留餘秒及提交UUID，不補滿五分鐘或派彩。重複確認不再次套用；關閉／換挑戰後過期讀檔回呼忽略。schema1舊檔仍保留，不搬資產至新挑戰。

大廳原有匯入亦套用預覽確認。背景檔案選擇器導致停錶時保持停錶，匯入後若原先暫停仍回暫停，需要繼續。首頁資料頁可續玩；牌局內設定只提供備份操作，避免按續玩意外丟棄當前手。

## 說明與回報

五分鐘規則說明及五款完整教學。instructions.mjs由原牌桌規則抽成共用來源，牌桌玩法視窗亦使用它，避免賠率及規則維護兩份。設定不顯示商店／道具或錯誤的常駐計時提示。

問題描述上限2000字，裝置資訊（瀏覽器及畫面尺寸）由玩家選擇，預設不附。可複製純文字或下載TXT，Clipboard不可用／拒絕有下載退路；GitHub入口已確認原倉庫has_issues=true，需玩家登入、自行貼上及送出。沒有自動建立Issue、傳送訊息或上傳任何診斷，不附姓名、資金、牌局、存檔或提交ID。玩家自行在描述輸入的資訊需自行檢查，頁面提醒GitHub問題為公開內容。
