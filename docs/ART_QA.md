# 人物、桌椅與遮擋檢查

## 使用者指出的v3問題

部分荷官看起來插入桌面，部分賭客臀部與椅子不對齊或像坐空氣椅。上一輪的目視檢查主要確認人物數量、外觀與場景保留，未充分確認所有桌椅接觸關係，不能把該輪結果當成物理合理性已通過。

## 本輪修正假設與最小驗證

- 假設：人物是在既有家具上直接生成，沒有一致對應座墊／地面與桌面遮擋，造成身體似乎穿過桌面、臀部沒有承托。
- 修正：荷官移至桌後側外角，軀幹在桌面範圍外，盡可能露出地面上的腿／鞋；人物椅子允許小幅旋轉／移動／重畫，以配合臀部位置，桌位與場景保持。
- 最小驗證：逐款逐桌目視臀部與椅墊、椅背與軀幹、鞋與地面，以及荷官身體在桌外、手臂連接和桌邊遮擋。這是2D視覺檢查，不是碰撞引擎或物理模擬測試。
