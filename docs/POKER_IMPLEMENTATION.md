使用者於21點發布後要求「下一步開發」。依TEXAS_HOLDEM.md第22–39題的已確認框架，接入第四桌；輪盤仍未實作。本輪是可玩原型，不宣稱Safari或平衡已通過。

## 玩家體驗與範圍

大廳入座全部資金 → 開始一手／自動盲注 → 每人兩張底牌 → 翻牌三張、轉牌及河牌各一張、每輪下注 → 棄牌獨贏或攤牌 → 主池／邊池分配、保本補償 → 判達標／破產 → 保存完整局 → 再玩或離桌購物。

六人桌，玩家一人加五名不同姓名／風格的電腦。六副21點、八副百家樂與德州單副52張彼此獨立。每手全新公平Fisher–Yates洗牌、每輪公共牌前燒一張；AI不讀其他底牌、未發牌、透視資訊或玩家道具。

牌型以七張中最佳五張，包含不用任何底牌的公共牌成牌、A2345、兩組三條、踢腳比較。無抽水，花色不決定勝負。金額都是整數美分，邊池按各人投入門檻分層；棄牌錢留池但不能贏。相同牌力每池平分，零頭由莊位左側起順時針分；單人未被跟注的多餘投入退回，不算抽水。

D莊位每手輪轉，左側小盲、再左大盲。翻牌前大盲左側先行，之後莊位左側先行。盲注不算主動行動，大盲保留過牌後的加注機會。完整加注幅度至少上一完整加注幅度（初始大盲）；可少於完整幅度的僅為實際全押，短加注不重開已行動者加注權，累積對該玩家達完整幅度才重開。只有一名尚有籌碼而其餘全押時，只需補足實際跟注，不允許向無籌碼對手額外下注；其後自動發完公共牌。

## 操作與呈現

六人枱布沿用B翠綠／酒紅金框、真實卡牌PNG及五色籌碼。上方對手、中間公共牌／彩池、下方自己的手牌及當前操作；此為六人桌工程配置，不強制百家樂35／65。

加注五色快捷值隨起手資金調整；顯示「加至總額」，選值後按加注才扣款，不把金額選擇當立即投注。可輸入美分、跟注、過牌、棄牌及合法全押；非法金額、資金不足、短碼未重開或舊回合token都拒絕。每個真實下注／彩池／座位餘額有DOM落點，共用600msChipFlights及混色堆疊，行動完成先等600ms讓下注落枱，再收注及發牌／攤牌，最後派彩。

一般螢幕五名對手一排；手機三列兩排。短窄屏隱藏對手牌背縮圖，保留名字、餘額、投注與狀態，明細可查看所有公開牌況及主池／邊池；自己的兩張牌和公共牌保留。卡牌以實際容器尺寸計算寬度及等比例，不拉伸貼圖。換牌時直接點自己一張牌，透視選尚未棄牌的對手；選擇本身不扣券，實際點選才扣。主要動作44–48px；原生明細／背包／速度面板承載次要資訊，沒有額外常駐統計欄。

對手暗牌沒有隱藏的aria牌名；合法透視只輸出一張，攤牌只揭未棄牌手，棄牌者保持隱藏。使用者原先刪除的手圖保持不存在，沒有新咪牌。

## 時間、道具與保存

玩家每次行動30秒，超時可過牌就過牌，否則棄牌。正常／快速只改下一次發牌、AI與攤牌等待；玩家上限不變。透視不重置倒數，換牌動畫同樣扣原行動剩餘時間，歸零則換完立即按超時規則處理。使用既有Game.tick；暫停／背景遮桌、動畫及倒數停止，頁面仍存活則按繼續恢復原局。未完成手不能離桌買道具。

每手所有操作合限一件，只有玩家可用，沿用無免費配給及購買前資金10%價格。保本券首次行動前（含開局前）可用，按玩家全手所有彩池實際派回與總投入的淨虧損退50%，向下取整，補償來自活動不扣AI。透視在自己行動時，選一名未棄牌對手的隨機一張底牌。換牌只限翻牌前、首次行動前，選自己一張從剩餘牌隨機換入，舊牌棄置不再用。

入座全資金並沒有另設第二個錢包，profile.bank即玩家可用桌上籌碼；投入立即扣，未結算底池不能花用。Game統一結算一次，更新AI實際籌碼及玩家補償後才判達標／破產。只寫完整一手的checkpoint，schema1新增可選pokerTable={button,speed,nextId,seats:[id,style,stack]}，保存AI剩餘籌碼及莊位，沒有保存底牌或未完成牌局。原blackjackShoe、baccaratShoe、背包、自由／競速槽與舊檔保持。

離桌保留有籌碼AI，不隨玩家資金重設；輸光者下一手新人補位。其他桌完成局也攜帶pokerTable。完全關閉／重整回最後完成存檔，未完成手作廢；暫停並非局中持久快照。新挑戰重置牌桌；首次入座前舊檔缺欄位則建立五名AI，沒有送道具。

## 可調校工程預設

這些是未指定細節的初始預設，不是使用者永久定案或平衡結論：

- 起手資金不足$1：大盲為該資金，至少一美分；小盲為大盲一半向下取整、至少一美分，實扣不超本人籌碼。一般大盲：資金<$1,000為$1；<$10,000為$10；<$100,000為$100；<$1,000,000為$1,000；其上為$10,000。每手開始前才更新，手內固定。
- 新AI帶入玩家當時20–120%的101個整數百分比等機率，向下取美分、至少一美分；已有籌碼者保留。初始五種風格，補位風格隨機；無抽水／額外賞金。
- 難度在起手資金$1,000與$100,000分級；以自身手牌／公共牌、跟注價格、風格、隨機估值誤差及詐唬作決策，高級估值誤差較小。這是輕量原型AI，不是均衡策略或經實玩證明的強度。
- 正常每張450ms、AI1200ms、攤牌1600ms；快速180／300／600ms。發最後一張後保留同等一個動畫步，收注等待600ms，籌碼弧線仍600ms。切速度不追溯改當前剩餘等待。
- 預備桌不設自動開局，等玩家按開始；這段仍按原規則計有效遊玩時間。分頁暫停或商店停表。無額外頭像PNG，座位用不同姓名／風格徽章，卡牌／枱布／籌碼重用既有正式素材。
