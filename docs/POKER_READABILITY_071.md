# 0.7.1 牌型提示、公共牌間距及主畫面整屏

2026-11-02；維護／發布。依使用者三點回饋修正0.7.0：橫向應有牌型提示、公共牌與彩池上移置中但不可碰對手、主畫面不用上下捲動。第3點已提問範圍，尚無回答時按已向使用者說明的假設，同時處理首頁、大廳與德州牌桌；不是另行確定所有頁面都不得內部捲動。

## 顯示修正

- 橫向自己的姓名下方重新顯示14px牌型，使用既有pokerBest計算；翻牌前顯示等待公共牌，棄牌顯示已棄牌。只顯示自己的最佳牌型，不新增對手勝出牌型或頭像。原透視結果仍可在更多／紀錄查看。
- 共同標題列顯示「公共牌 · 彩池 $…」，和五個公共牌位置整組置中。fitPokerSurface量測上三位對手框、底牌與投注文字的最下沿，留8px後才可放公共牌；自己手牌框前再留10px。剩餘空間取偏上的位置；短屏適度收細公共牌容器並沿既有等比例卡牌fitter。原13籌碼飛行目標、金框及動效保留。
- 首頁依可視高度配置；橫向左右分欄，直向合適縮排。姓名／模式／開始／繼續保留，匯入及聲效移進「存檔及音效」。選項開啟後切換音效不自行收起。軟鍵盤極短高度可在表單內部捲動，不以整頁長表單處理。
- 大廳HUD、地圖與底列合成一屏。將原1672×941正式PNG與五個入座按鈕作同一場景等比例縮放，避免圖片與按鈕位置分開。商店入口在地圖上方，存檔／主頁與保存說明在底部；手機入座按鍵至少44px高。沒有替換美術或新增地圖。
- 故事卡亦按可視高度，短橫屏使用兩欄；必要時長內容只在卡片內部捲動。德州手機主殼限制外部溢出，原生dialog仍在殼外。

## 根因及驗證

0.7.0用`.pk-player-label>span{display:none}`把整段自己牌型一併藏掉；本版用專用pk-hand-hint恢復。公共牌原固定bottom82px，無法利用較高螢幕的中央空間；本版以實際DOM可用帶決定位置。首頁原min-height加上大間距長表單；大廳窄版則將地圖和五個入座按鈕逐列疊起，造成整頁變長。

新增3個德州檢查（自己的兩對／等待／棄牌、可用帶邊界、縮放後恢復尺寸）及2個大廳場景比例檢查。原規則、30秒、金錢、AI、道具、暫停、聲效與完成手保存均沿既有owner，沒有變更schema1。總計256項：247規則／元件、3單檔封裝、6 Pages；10,000局模擬保留。另一次性渲染並解析實際home／lobby模板，核對標籤平衡、五入座鍵在地圖場景內、底列在場景外；不當成瀏覽器排版驗證。

browser_smoke.py補自己的牌型可見、公共牌置中及與兩端距離、首頁／故事卡／大廳頁高、主要控制位置；同步更新收合聲效入口。僅Python語法通過。沒有瀏覽器工具，沒有重試既有失敗的HTTP／Chromium IPC；Safari觸控、真DOM邊界、鍵盤、安全區及各尺寸仍UNVERIFIED。

## 閱讀審核與裝置矩陣

程式／版面層暫評3/5；牌型14px、公共牌標題14px、金額16–18px、主動作18px。順序為自己決策／手牌★★★★★、公共牌／彩池★★★★☆、對手行動★★★☆☆；牌型回復在自己原框空位，未增一排常駐HUD。首頁與大廳次要項目收合；主要動作44px，既有德州頂欄35.2px保留使用者明確例外。牌型有文字及ARIA，原五色籌碼與冷色字保持。首30秒主要按鍵及入座可找，操作回饋仍待實機。續玩意願暫估3/5、介面投訴風險粗估25%，只為設計估計，不是實測或商店評分預測；主要風險仍是小對手牌、極短畫面、鍵盤。

568×320、667×375、740×360、844×390、915×412的德州位置數學／比例輸入有檢查；390×844、320×568、720×1280、1080×2400、768×1024、1024×768、1440×1000的真頁面只補smoke路徑，全部瀏覽器／Safari結果UNVERIFIED。只支援繁體中文，未新增其他語系承諾。
