# 0.6.0 手機三桌介面

使用者已授權實裝大小v2與百家樂手機橫向預覽，並明確要求手機輪盤改成鎖注後彈出轉盤。此指示取代手機輪盤舊6:4；一般桌面／平板維持原6:4及大小上下分區。21點與德州本輪不套新布局。

## 玩家行為與範圍

- 手機橫向為主要設計；layout viewport寬≤1100且高≤600，或窄版寬≤679時啟用。使用layout尺寸判斷布局，visualViewport只量可見高度，避免軟鍵盤改變遊戲桌模式。這是工程預設，不鎖定裝置方向或強制全螢幕。
- 共通：返回、桌名、可用資金、有效時間、本局投注、倒數與暫停合成頂列，隱藏重複導覽；長金額保留完整DOM／明細，窄版收合次要時間，直向最窄版將本局金額留在操作區。安全區採CSS env。
- 大小：無常駐骰盅；正式50格盤面保持原分區與骰面圖案。底部五色籌碼、自訂、全押、鎖注、清除與更多；較窄尺寸分行以保留44px主按鍵。明細／精準下注／放大／道具／規則收在更多，直接使用原來的控制節點及事件。
- 百家樂：連續枱布，開牌／下區32:68手機比例，下區含六格及操作，不是放大六格而把牌縮成角落。卡牌由真實容器量尺寸；三張牌與換牌的44px選擇、咪牌、旁注、保本及牌靴保持。一般手機橫向保留底部工具列，小尺寸改更多。
- 輪盤：下注時只有擴大盤面，無右側常駐轉盤；仍保留50格、雙零、原投注幾何、放大及精準選單。轉盤使用同一真實輪序及動畫，而非GIF。

## 小窗生命週期

`MobileRoundReveal`只讀Game，無setTimeout、亂數、錢包或checkpoint寫入。

1. 只在有注鎖定後（手動或原下注倒數到期）跟隨revealing／rou-spinning打開；空注跳過不顯示假開獎。
2. 大小沿用900ms搖骰及揭盅聲，額外提盅視覺700ms用CSS負delay與paused狀態；不更改聲效或引擎時序。預覽GIF的2.4秒是當時分鏡值，不當成已修改玩法。
3. 輪盤沿用4.8秒輪球動畫，仍從原remaining取得負delay；旋轉或重渲染不重開動畫、不重抽號碼。
4. 大小重擲三骰選一／接受、輪盤重轉／接受仍在小窗內維持原10秒；主盤面inert，主HUD暫停保留，不能透過關窗跳過選擇。
5. Game照舊先完成唯一結算／保存；展示層再停留結果1400ms，可按返回盤面或自動關閉。此停留只管顯示、不延後／重複派彩或保存。一般牌局在結果等待期間照原Game邏輯計時；已達標／破產的Game仍按原規則停止，不用展示層另計分。
6. 暫停／背景遮桌、停Game倒數與聲效；本地結果停留也停。恢復同一r.remaining，原生更多面板在動畫／暫停前關閉，不能遮住暫停遮罩。
7. 換桌、下一局或改回一般桌面時，清除顯示狀態；再次轉手機的未完轉動仍讀同一局。完成局不重新彈出舊結果。

鍵盤：小窗焦點與暫停鍵一起循環，結束返回結果操作；更多／明細使用既有原生dialog，關閉還原節點及焦點。Esc維持暫停，並非免費略過動畫。

## 程式與資料

- `src/sicbo-view.mjs`由app原大小模板移出，作為可驗證的顯示函式；桌面內容及正式50格不改。專有escape名稱避免單檔封裝時與app全域名稱衝突。
- `table-layout.mjs`新增手機判斷、只讀小窗狀態與更多原生dialog；app接原advance／render／resize。
- 三桌視圖及CSS分別套手機容器，一般桌面維持；package／Pages增加新視圖，所有模組快取版本0.6.0。
- Game、rules、storage、聲效邏輯與素材原檔不改，只更新既有模組import快取。schema1、完成局保存、兩牌靴、AI桌面及五桌共用庫存保持。
- 回退首選`MOBILE_TABLES_ENABLED=false`並更新快取／封裝，即回既有桌面布局；不要清除保存或復原手圖。前版main為90b2f88f55ac09f3efa79e306f365b2bdb86adad。
