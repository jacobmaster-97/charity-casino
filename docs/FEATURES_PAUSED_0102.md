# 0.10.2本機 · 商店與道具暫停開放

本輪分為兩個範圍：21點賭枱重設計先預覽，待使用者確認；商店與道具功能先在本機隱藏／停用。GitHub保持0.10.1，沒有遠端更新。

## 實作

`src/rules.mjs`的`GAME_FEATURES = Object.freeze({shop:false,items:false})`由正式app傳入Game。大廳商店、五桌背包與道具按鈕、道具佔位文字及規則介紹一併收起；品牌及大廳說明不再提示購物。舊商店程式／素材與庫存保留。

Game將能力配置與存檔分開，restore不能將關閉的功能重新打開。購物／購買及五桌通用／直接道具API拒絕操作，app亦防止隱藏入口舊事件開啟選牌流程。大小存有重擲券時不再自動進重擲階段，正常派彩一次，保留原庫存。金額／計時／牌局及完成局保存維持既有規則。

沒有清空庫存、退款、改價格、移除資料欄位、改派彩或刪素材。Game底層不傳配置時保留原功能，供舊規則及未來重開回歸；正式app一律使用關閉配置。

日後重新開放：使用者決定時，將上述兩個開關改為true、重新封裝及同步整套cache版本，再跑回歸／裝置驗證。保留庫存可直接繼續使用，無需存檔遷移；沒有定時自動重開。
