# 大小介面0.1.4：上骰盅、下盤面與一體投注控制

使用者提供的兩張圖片是本次依據：第一張為上下配置與底部投注區草圖；第二張為平板Safari只看到部分盤面、右側投注欄佔寬的實況。另要求五款快捷籌碼使用不同顏色。

## 根因與最小修正

舊版src/app.mjs以table-layout將遊玩區與320px投注欄並排，src/styles.css另將盤面最小寬度固定1560px；即使平板有1280px，盤面仍遠超左欄寬度。新版本移除側欄布局，改為全寬骰盅區→完整投注盤→下方控制區，原SVG改以印刷範圍viewBox 110 245 1380 555呈現，座標與全部50種投注ID／賠率不變。

盤面及下方控制置於同一個翠綠枱面框內；全盤預設width:100%、min-width:0，不要求橫移。放大按鈕才啟用可移動的大盤。手機完整總覽的細字／細格會較小，提供放大及48px級精準選格下拉＋下注按鍵作同等操作入口，避免為看齊盤面而只能點極細格。兩種入口都經Game.addBet，不放寬金額或下注時機。

## 所有原投注功能的落位

- 投注與餘額摘要、每次金額：盤面下方第一列。
- 五色快捷籌碼、自訂金額、全押：下方金額區；隨每局資金調整面額、局內穩定，選中金額不自動加大。
- 鎖注開骰、清除全部：下方操作區。
- 投注明細、移除單項：下方可展開區。
- 本局道具、透視骰子選擇、持有量與使用鍵：下方可展開區。
- 手機精準選格：下方可展開區。選項涵蓋全部50格，已開骰則停用。

骰盅區保持可開骰／重擲／結果原有流程；結算、離桌、再玩、保存功能保持。暫停遮桌、動畫同步凍結及完成局存檔契約不變。

## 五色實際素材

public/art/sicbo-board-b/chips-five.png為image_gen生成原始RGBA PNG，2172×724，完整複製；來源／SHA記於同目錄assets.json。從左到右為象牙白、酒紅、寶藍、翠綠、紫，五個atlas區域以執行期SVG明確clipPath取格，不依賴overflow屬性，不改原PNG。中心碼值是文字層，能隨資金面額變更。

選擇、飛行與落枱使用同一顏色映射；不同面額疊在同格時保留各自顏色，最多呈現三層，總額另以文字顯示。面額依快捷列由小至大分配五色；自訂金額取不高於該值的最近快捷面額顏色，精確金額仍可在輸入與明細查閱。動畫仍為420ms飛入＋180ms輕彈，僅接受成功交易後播放。
