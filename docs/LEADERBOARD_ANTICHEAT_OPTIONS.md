# Cloudflare 精簡排行榜：已選基本防護

2026-11-02（香港）；規劃，未實裝／部署／建立Cloudflare資源。

## 目前需求與決策狀態

使用者希望整個五分鐘流程在遊戲內處理，完場才上傳名稱及最終金額，不記錄下注驗證、暫停同步或派彩；隨後補充亦希望攔截作弊成績。兩項需求需明確區分「長期記錄」與「遊玩期間短暫驗證」，不能將兩欄上傳誤稱為足以驗證真實遊玩。

使用者已選「只上傳名稱金額，接受基本防護」。不採遊玩期間伺服器狀態驗證，不接管五分鐘／暫停／派彩，不建立伺服器牌局／操作流水。以下短暫驗證提案只保留作未採用的參考，不是待批准或下一步要求。

## 兩個可選範圍

| 範圍 | 可以處理 | 無法據此證明 |
| --- | --- | --- |
| 完場只上傳名稱＋金額 | 欄位型別、暱稱長度／安全顯示、金額非負及精度、限流、重試去重、人工移除可疑紀錄 | 是否真的玩滿有效五分鐘、籌碼是否被修改、開獎是否被改、是否以舊存檔／多次重播挑選結果 |
| 遊玩中短暫伺服器狀態（建議，待用戶選擇） | 後端裁定資金與合法操作、隱藏亂數／未揭牌、暫停及有效計時、唯一結算及最終金額 | 不能單憑此保證操作者是真人或杜絕自動化；也不保證零作弊 |

基本限流、CAPTCHA或前端加密／hash，都不能證明上傳金額是按本遊戲合法取得。前端可讀的簽名密鑰或完整亂數種子亦不能作秘密；完整種子可能讓玩家預知未來結果。後端可以標記異常高分作檢查，但未定上限前不應把合法罕見高倍數勝出直接當作弊刪除。

## 未採用的短暫狀態驗證提案（非現行實作範圍）

1. 開局由Worker建立run，資金固定10000分、有效餘時300000毫秒；記錄規則版本、資金、道具、目前牌局、伺服器私密亂數／牌靴、狀態版本及操作序號。
2. 只在會改資金或影響遊戲結果的操作發API，不逐動畫幀上傳；伺服器確認投注、派彩及合法行動。大小／輪盤可在鎖注或重擲選擇等節點處理；21點／德州需按每次合法行動處理，不能只靠一開始或最後的金額範圍檢查。
3. 未揭示的牌與後續亂數留在伺服器，只回前端當下允許看到的內容；前端保持目前貼圖、發牌、籌碼動畫與觸控。
4. 有效時間及暫停也要確認：購物／大廳照計；手動暫停或切背景停，明確繼續後保留總／行動餘秒。背景請求遺失與離線的同步邊界仍須設計及實測，不能保證visibility/pagehide請求一定送達。
5. 時間到禁止新玩家決策，自動收尾已下注局並唯一結算；全押可用0但尚未派彩不先判破產。
6. 完場清除完整牌局及下注暫存，只保留待公開的已核實結果摘要。玩家按上傳時，伺服器把自己的結果發布到排行榜，不採信重新輸入的最終金額。對外只顯示名稱與金額。
7. 去重、結果所有權及操作順序需要內部技術ID／序號；不是額外公開玩家遊玩紀錄。同名玩家不能只按名稱視為同一人；若要每玩家只留最佳，仍需匿名識別方式。確切資料保留期限／未上傳結果處理待定，不自行保存永久完整行動歷史。

可以只保存目前狀態並覆寫，不必永久保留每次下注的流水；但這仍會有遊玩期間API和短暫資料庫寫入，與「每人只有一次上傳請求」不同。D1的私密run表只可由Worker存取，排行榜查詢僅輸出公開兩欄。

## 成本及容量的影響

兩欄排名資料仍可沿用平均1KB（含索引）及預留20–30%的保守容量估算；這不是實測，暫存run亦會佔部分容量。每局多次操作／暫停請求、索引讀寫與Worker CPU必須另量測。原「只完場一次上傳」的每日玩家量估算不能直接套用到已驗證玩法。Cloudflare免費Worker每次10ms CPU尤其要驗證德州AI／結算的峰值，不能未測就承諾全套免費可承載的人數。

## 基本防護的現行規格與驗收

已選基本版本：名稱1–16字且去首尾空白，作純文字顯示；金額只接受規定的非負精確數值，拒絕NaN／Infinity、錯誤型別、超出支援精度與過大請求；使用參數化SQL及限制上傳頻率。同一完場提交使用穩定重試鍵以避免網路重送產生重複成績，這不證明真人或一人一帳號。同名不自動覆蓋；每人最佳或每局一筆仍另定。正常遊玩期間不發驗證請求。異常高分可供管理檢查，但不以未確認的金額封頂直接判作弊。

驗收：非法名稱／型別、負數／溢位、重試、限流、同名與安全顯示。以下僅為未採用完整驗證模式的參考：修改前端金額不改後端資金、舊存檔不能帶入、冒用run被拒、重複派彩只執行一次、過期／亂序行動被拒、改手機時間無效、paused禁止下注、背景與恢復保持餘秒、到時自動收尾、未揭牌不出現在回應、清除暫存不影響已發布成績。尚未執行這些檢查。

## 現行服務流程

GitHub Pages本機完成五分鐘或破產結算 → 玩家按上傳 → Worker基本檢查 → D1寫入名稱／最終金額 → 所有人查榜。無全程後端驗證；雲端不判斷是否真的玩足時間或依法取得金額。API與資料庫可有去重所需技術ID／伺服器產生的提交時間，屬設計建議，非額外玩法紀錄。尚未實裝或部署。
