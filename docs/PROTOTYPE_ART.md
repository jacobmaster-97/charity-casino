# 原型B素材生成與匯入

全部為實際PNG；原圖未裁切、縮放或程式修圖，保留生成來源。B大廳沿用v4。來源、尺寸及SHA-256詳見public/art/prototype-b/assets.json。

- table.png：參照B大廳的墨線、賽璐璐、翠綠絨布、酒紅木邊及金色飾線。略俯視，中央85%空白，不畫人物、骰、牌、籌碼、字、投注格或UI。實際1672×941 RGB。
- dice.png：兩欄三列，正面1–6點依列序排列。象牙白、黑點、墨線、暖色陰影，無側面／文字／格線。實際1024×1536 RGBA，以CSS取格。
- props.png：兩欄兩列，依序保本券盾牌、透視鏡、重擲券骰與箭頭、綠色籌碼疊。無字／面額。實際1254×1254 RGBA。票券略跨等分欄界，runtime第一欄以190%水平背景尺寸保留邊緣；實際縮小顯示待瀏覽器目視。
- dome.png：翠綠煙色玻璃、黃銅底與頂鈕，無骰、桌、字，略俯視正面。實際1254×1254 RGBA；下注顯示，揭曉以三個骰面取代。

透明圖直接使用image_gen透明輸出。B大量使用綠色與透光玻璃，避免綠幕污染；本輪無去背或色鍵清除。原始生成檔均保留。

桌面是背景層；骰盅、骰子、投注、籌碼金額、結果由runtime控制。只有一款綠色籌碼圖，五個金額按鈕重用，沒有宣稱完成五種色款。換牌券、重轉券及其餘四桌素材仍待製作。

來源為本輪image_gen原創生成，未引入第三方素材庫；生成來源記錄不等於獨立法律審查。沒有音效或外部字型下載。
