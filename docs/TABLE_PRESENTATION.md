# 五款遊戲共同枱面與投注呈現標準

## 已確認範圍

**最新正式製作基準：大小0.1.4。使用者已表示「滿意效果」，並確認其餘四款製作時也要有同樣要素。** 下方0.1.3為沿革；遇到布局差異以0.1.4上下配置、底部功能區及五色籌碼為準。

使用者於大小0.1.3實裝後指示：「其餘遊戲製作時也要有以上要素」。此標準適用大小、百家樂、德州撲克、21點及輪盤；大小已發布、百家樂0.1.5已發布，其餘三款待實作。本文件規定後續製作品質，沿用各款已確認的玩法與投注限制。

## 共同要求

- **枱面融合**：B港式賭片卡通風格，沿用翠綠枱布、酒紅木框、暖金色；投注區、標記與字樣融入實際枱面，籌碼等實物分層呈現，避免浮起的獨立盤面色板。
- **實際素材**：預覽使用可供遊戲直接載入的貼圖及UI層；記錄素材來源。保留清楚的牌面、點數、投注標記和人物接觸關係。
- **投注反饋**：有效下注才有籌碼飛入、輕彈落枱及同區堆疊；顯示累計金額和清楚落點。大小已確認的0.42秒飛入＋0.18秒輕彈、5px堆疊作共用預設，適配各款枱面比例；德州既定正常／快速模式仍有效。
- **大額操作**：按資金提供相稱的大額快捷籌碼或金額選項，保留自訂及各玩法容許的全押；不自動加大玩家已選金額。面額更新安排在局／手邊界，避免操作中跳動；德州手內合法加注範圍另依行動狀態更新。
- **精確金額**：可用資金、已下注及累計金額一致；大額簡寫須有精確金額可查。動畫只呈現已接受行動，不再次扣款、不先行派彩，也不因取消或減少動態改變結算。
- **電腦與手機／平板**：滑鼠點擊及觸控均能選籌碼、選投注位置；小螢幕優先確保可讀文字與可點範圍，必要時使用盤面內移動或適配布局。驗證Safari圖片、操作與不同方向；沒有實測不能宣稱支援驗收通過。
- **暫停配合**：暫停或切到背景時遮住牌桌、禁止操作，通關計時、行動倒數及進行中的動畫一起停止；按繼續才恢復。分頁仍存活時保留原局、籌碼、已用道具及剩餘秒數。完全關閉仍回最後完成局存檔。
- **舒適與復原**：支援減少動態，直接顯示已接受結果；旋轉、移動視窗或清除投注時正確收妥效果，沒有殘留籌碼或重複交易。保存仍只在局／手完成後開放。

## 後續每款的驗收

1. 用實際貼圖及UI確認枱面融合、文字與合法投注落點。
2. 檢查有效／無效下注、連續加注、改注／撤注、資金不足和大額操作；每次交易只計一次。
3. 驗證發牌／轉輪／開骰／結算及相應道具流程，畫面金額與規則狀態一致。
4. 驗證動畫中暫停、背景、繼續、減少動態、旋轉及完成局保存／讀取。
5. 核對根目錄與/docs發布圖片路徑，進行桌面、手機及平板實測並記錄證據；未執行項目明確保留。

此文件記錄共同要求；大小／百家樂目前線上為0.1.5；其餘三款尚未實作。

## 最新大小介面修正的共通延伸

使用者追加要求：骰盅／發牌展示區與完整盤面上下安排，投注內容及功能融入枱面下方功能區，不再以常駐右側投注欄壓縮盤面；五款快捷籌碼具不同顏色，選取、飛行及堆疊保持一致。其他桌依玩法適配，不沿用0.1.3固定最小1560px的預設截盤方式。細小螢幕提供放大或精準選格，保持全部原操作可用。大小已發布且效果獲使用者確認，詳見[SIC_BO_LAYOUT_014.md](SIC_BO_LAYOUT_014.md)。

## 已接受的0.1.4要素檢查表

- 展示區在上（依玩法為骰盅、發牌或輪盤），完整盤面在下；預設適應可用寬度。
- 投注金額、五款快捷籌碼、自訂、合法全押、開局／開骰及清除操作整合在盤面下方，不再以右側投注欄壓縮盤面。
- 投注明細／移除單項、道具及其選擇操作保留，次要功能可展開。
- 五款快捷籌碼為白、紅、藍、綠、紫；選取、飛行及落枱使用一致映射，混色堆疊保留原籌碼顏色，累計金額清楚。
- 隨資金提供大額籌碼，並保留各款下注資格／時機限制。
- 電腦滑鼠、手機／平板觸控，細格提供放大或精準選格；暫停時遮桌、禁止操作，計時與動畫同步停止。
- 使用實際可載入素材，保持B港式賭片風格與盤面融入枱布的效果；依各款已定玩法適配。

使用者的滿意回饋是效果確認，不代替未執行的跨裝置、規則與保存驗證。後續毋須重問以上共通方向，仍須完成各款實作及驗收。

## 使用者已確認的兩桌差異（0.1.9）

百家樂採一體賭枱，開牌／下注共用連續枱布，以金線上下分隔；大小採分開兩區，獨立骰盅與投注枱。兩者保持底部操作與整屏方向，不再把分開兩區視為所有桌的唯一形式。其餘三桌尚未獲指定一體／分區差異，不自動套用百家樂版式。詳TABLE_PRESENTATION_019.md。

## 21點一體版（0.2.0）

使用者最新明確要求21點採一體賭枱。上方莊家，下方玩家／最多四手及底部操作；主注、各分手、加倍追加與保險有獨立籌碼落點。小而矮的螢幕突出目前手牌，其他手保留摘要／籌碼及明細。沿用同一枱布／牌面／五色籌碼，不引入手圖，詳BLACKJACK_IMPLEMENTATION.md。


## 0.3.0德州撲克接入

六人桌沿既有B枱布，五名對手→公共牌及彩池→玩家手牌→底部當前操作的層次，不強制套百家樂35／65。五色大額加注、總額輸入、合法全押、各座下注／主池邊池收注及派彩動畫、次要原生面板及暫停同步。小屏折疊對手暗牌縮圖，保留名字／餘額／投入／狀態及明細，自己的兩張底牌及公共牌保持可見。對手暗牌僅合法透視一張或未棄牌攤牌時顯示，棄牌底牌不揭。素材重用，無新增手圖；裝置視覺仍UNVERIFIED。詳POKER_IMPLEMENTATION.md。


## 0.4.0輪盤接入

美式雙零輪序38格、下方完整50格盤面，沿上方展示／下方投注枱與底部功能區，五色大額籌碼、飛入混色堆疊及累計。窄高版數字改直排3×12，寬版12×3，三直列與十二數組的實際集合不變；兩版都有完整外圍，沒有邊線／交點。小格保留完整總覽及主動放大／精準選單，不縮小主要44px操作。使用同一座標資料印刷及定位HTML籌碼層，ChipFlights依實際DOM落點，旋轉後重排不改投注。上方實際輪盤／小球SVG減速至對應號碼，Game剩餘時間決定暫停與恢復進度。實機視覺仍UNVERIFIED。
