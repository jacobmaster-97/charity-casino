# 五款遊戲共同枱面與投注呈現標準

## 已確認範圍

使用者於大小0.1.3實裝後指示：「其餘遊戲製作時也要有以上要素」。此標準適用大小、百家樂、德州撲克、21點及輪盤；其餘四款仍待實作。本文件規定後續製作品質，沿用各款已確認的玩法與投注限制。

## 共同要求

- **枱面融合**：B港式賭片卡通風格，沿用翠綠枱布、酒紅木框、暖金色；投注區、標記與字樣融入實際枱面，籌碼等實物分層呈現，避免浮起的獨立盤面色板。
- **實際素材**：預覽使用可供遊戲直接載入的貼圖及UI層；記錄素材來源。保留清楚的牌面、點數、投注標記和人物接觸關係。
- **投注反饋**：有效下注才有籌碼飛入、輕彈落枱及同區堆疊；顯示累計金額和清楚落點。大小已確認的0.42秒飛入＋0.18秒輕彈、5px堆疊作共用預設，適配各款枱面比例；德州既定正常／快速模式仍有效。
- **大額操作**：按資金提供相稱的大額快捷籌碼或金額選項，保留自訂及各玩法容許的全押；不自動加大玩家已選金額。面額更新安排在局／手邊界，避免操作中跳動；德州手內合法加注範圍另依行動狀態更新。
- **精確金額**：可用資金、已下注及累計金額一致；大額簡寫須有精確金額可查。動畫只呈現已接受行動，不再次扣款、不先行派彩，也不因取消或減少動態改變結算。
- **電腦與手機／平板**：滑鼠點擊及觸控均能選籌碼、選投注位置；小螢幕優先確保可讀文字與可點範圍，必要時使用盤面內移動或適配布局。驗證Safari圖片、操作與不同方向；沒有實測不能宣稱支援驗收通過。
- **暫停配合**：暫停或切到背景時遮住牌桌、禁止操作，通關計時、行動倒數及進行中的動畫一起停止；按繼續才恢復。分頁仍存活時保留原局、籌碼、已用道具及剩餘秒數。完全關閉仍回最後完成局存檔。
- **舒適與復原**：支援減少動態，直接顯示已接受結果；旋轉、移動視窗或清除投注時正確收妥效果，沒有殘留籌碼或重複交易。保存仍只在局／手完成後開放。

## 各款落點與規則適配

| 遊戲 | 枱面與籌碼的呈現 | 必須維持的規則 |
| --- | --- | --- |
| 大小 | 50格印刷盤面、各格堆疊與累計 | 已實裝0.1.3；大小遇圍骰輸，其餘投注按原規則 |
| 百家樂 | 莊／閒／和投注區，籌碼落在當前所選一區；改押時舊區清理，金額同步 | 每局只押一項；佣金、和局退本金及道具時機保持 |
| 德州撲克 | 六人枱的各座位下注、收注至主池／邊池、按結算派回籌碼 | 玩家跟注／加注／全押須合法；清楚區分本輪投入、剩餘籌碼與底池；不重複計資金 |
| 21點 | 主注、各分牌手及保險各有清楚落點；加倍／分牌追加籌碼對應正確手牌 | 最多四手、保險獨立金額與資格限制；共用資金不可重複使用 |
| 輪盤 | 美式0／00盤面與已定外圍區，各項獨立堆疊及累計 | 多項下注；不因盤面美術自行加入邊線、交點或首五數 |

## 後續每款的驗收

1. 用實際貼圖及UI確認枱面融合、文字與合法投注落點。
2. 檢查有效／無效下注、連續加注、改注／撤注、資金不足和大額操作；每次交易只計一次。
3. 驗證發牌／轉輪／開骰／結算及相應道具流程，畫面金額與規則狀態一致。
4. 驗證動畫中暫停、背景、繼續、減少動態、旋轉及完成局保存／讀取。
5. 核對根目錄與/docs發布圖片路徑，進行桌面、手機及平板實測並記錄證據；未執行項目明確保留。

本次只更新規格，沒有實作其餘四款或改動線上0.1.3。

## 最新大小介面修正的共通延伸

使用者追加要求：骰盅／發牌展示區與完整盤面上下安排，投注內容及功能融入枱面下方功能區，不再以常駐右側投注欄壓縮盤面；五款快捷籌碼具不同顏色，選取、飛行及堆疊保持一致。其他桌依玩法適配，不沿用0.1.3固定最小1560px的預設截盤方式。細小螢幕提供放大或精準選格，保持全部原操作可用。大小候選詳見SIC_BO_LAYOUT_014.md。
