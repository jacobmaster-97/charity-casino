# 使用者文本修訂0.13.2

來源：使用者回傳「五分鐘賭神_全部遊戲文本_修改稿_v0.13.1.docx」。1,086列ID及原文全部核對，修改欄33項，其中12項為「刪除」，沒有追蹤修訂／註解或原文欄變動。檔案SHA記於docs/text/revisions/TEXT_REVISIONS_0132.json。

## 實作範圍

- 按編號局部套用，未填修改欄的原文保留；沒有新增上一輪設定建議中的音量、放大或全押確認。
- 序章及暫停刪除指定裝飾／說明元素，指定按鈕刪除整個DOM，不留下空按鍵。
- 設定刪除指定存檔說明／匯入／舊版匯出入口；無存檔時一併略過空白存檔區，有存檔仍可繼續。原存檔原樣保留，大廳的存檔功能及底層匯入／匯出仍保留。
- 大廳圖片改空alt而保留圖片及五個具名入座按鈕；指定頂欄的輔助名稱縮短。
- 德州只刪「牌型：」前綴，真實牌型與aria-live保留。
- 龍虎榜將「龍虎榜首／名次／參賽者」改「榜首／排名／賭神名稱」，同步可見欄標與語意表頭，刪除少量成績提示；沒有刪除完整空榜／錯誤狀態、數值或分頁。
- 公開API、D1、遊戲規則、資金精度、派彩、計時、存檔、貼圖與音效保持。只更新前端快取版本至0.13.2。
