# 大小枱面與籌碼動畫：0.1.3

2026-10-30使用者確認v2枱面效果，可實裝；動畫與節奏已先確認。將同一組原始PNG及透明印刷層接入實際Game.addBet，所有50投注ID／賠率保持。資金以美分為單位，不把預覽的美元示範數直接當遊戲數值。

## 玩家操作

選快捷籌碼、自訂金額或全押，再點枱面投注格。成功下注才飛入，0.42秒弧線＋0.18秒輕彈；同格最多顯示三層，偏移5px，金額累計。失敗下注不產生籌碼。右側／手機下方投注列表可移除單項或清除全部；開骰後盤面保留作本局投注紀錄，格子不能再下注。沒有另新增賠率或改結算方式。

## 實作與邊界

- src/board.mjs是SVG盤面及短期動畫；Game是投注／資金／完成快照的唯一所有者。動畫完成／取消不修改籌碼或存檔。
- public/art/sicbo-board-b/的枱面、平面金色骰符、立體籌碼皆與已確認候選PNG逐位元一致。來源／SHA見assets.json。
- 桌面／手機用同一盤面。最小1560 CSS px確保密集文字與格子不被縮小；容器內橫向移動，手機也可縱移，頁面本身不需要橫移。大額籌碼、自訂、全押保持原流程。小螢幕需要滑動查看另一端投注，屬取捨，尚待實機評估。
- SVG格子支持滑鼠、觸控、Tab＋Enter／空白；透明矩形全區接收點擊。投注列表保留精確金額，枱面大額使用既有精簡標籤。
- 暫停／背景／規則視窗遮住牌桌及飛行籌碼、凍結動畫，繼續後恢復。移除、清空、開骰、換局會清理相關飛行效果，滾動／旋轉則直接顯示已接受籌碼，避免落點錯位；不延遲結算。
- reduced-motion跳過飛入，立即顯示籌碼。無WAAPI時也直接顯示，不妨礙投注。
- schema仍1、保存槽不變；更新不清除舊存檔。模組及入口統一?v=0.1.3，根目錄及/docs圖片路徑檢查保留。
