# 大廳背景貼圖生成規格與來源

## 共同生成規格

單張橫向16:9、不透明、全幅靜態大廳背景PNG，直接作HTML5遊戲背景層；不要概念拼圖、展示框架、文字、標題、數值、HUD或按鈕。稍俯視固定2.5D／orthographic相機。上方約16%低干擾暗牆供HUD，底部約8%低干擾地面。綠色桌布、酒紅、奶油白、金色的賭場環境。

五個靜態桌具目標中心：大小(0.23,0.36)、百家樂(0.77,0.36)、德州撲克六椅圓桌(0.19,0.70)、21點半圓桌(0.50,0.75)、裝飾輪盤桌(0.81,0.70)。商店櫃位在後牆(0.50,0.22)。留桌間空隙，不加桌名或鎖門，大小桌罩內恰好三顆骰子。牌局結果與操作交給獨立動態層，圖中賭桌是環境裝飾。

## 各風格生成規格

- A：1990年代PC電子賭場的2.5D繪製／預渲染桌具，酒紅木料、翠綠絨布、黃銅燈、復古塊狀幾何及少量dither，溫暖微暗燈光；不是現代寫實賭場攝影，不加UI立體框或標題條。
- B：原創港式賭片氛圍漫畫背景，清楚墨線、賽璐璐陰影、手繪酒紅地毯與翠綠桌；後牆以原創灰髮眼鏡男主持及棕色短髮女主持裝飾壁畫，不是前景角色或演員仿像。其他構圖遵守共通規格。
- C：16-bit年代像素美術，清楚方形像素與階梯輪廓、約32色的視覺目標、點陣陰影、統一像素尺度，避免反鋸齒、模糊、向量輪廓及平滑漸層。這是風格指示，原始PNG色數與像素網格不因此視為已驗證。

## 匯入規則

PNG以工具輸出的原始尺寸複製保存，沒有重繪、裁切或縮放原圖。A／B建議linear，C建議nearest／CSS image-rendering: pixelated。原始生成圖保留，交付副本另存public/art/styles。所有風格仍是候選，並非已選定美術。這份規格記錄生成意圖；實際桌位依目視輸出錨點另記，不能把目標座標誤當生成精度保證。
