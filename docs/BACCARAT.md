# 百家樂玩法規劃

## 已確認基本規則（第 49 題來源指示）

- 使用八副標準撲克牌，不含鬼牌。
- A 計 1；2–9 按牌面；10／J／Q／K 計 0。每方總點數取個位數，點數較高者勝，同點為和。
- 開局依序發閒、莊、閒、莊，各取得兩張底牌；每方最多三張。
- 任一方初始兩張合計為 8 或 9，雙方均不補牌，直接比點數。此判斷優先於下方全部補牌規則。
- 沒有天牌時，先判斷閒補牌，再判斷莊補牌；玩家下注但不決定要牌或停牌。
- 閒 0–5 補一張，6–7 停牌。
- 閒停牌時，莊 0–5 補一張，6–7 停牌。
- 閒已補第三張時，依下表判斷莊；所列第三張是該牌自身的百家樂點值，不是閒方最後總點數。

| 莊初始點數 | 會補牌的閒第三張點值 |
| --- | --- |
| 0–2 | 0–9 全部 |
| 3 | 除 8 之外全部 |
| 4 | 2–7 |
| 5 | 4–7 |
| 6 | 6、7 |
| 7 | 不補 |

## 已確認賠率與投注（第 50 題 A、第 51 題 A）

全部為淨贏賠率，中獎另退該注本金。

| 投注 | 中獎淨贏賠率 |
| --- | --- |
| 閒 | 1:1 |
| 莊 | 0.95:1，扣贏款 5% 佣金 |
| 和 | 8:1 |

- 開和時，莊／閒主注退本金，和注派彩。
- 不加入免佣金莊六點半賠規則。
- 不開放莊對、閒對、幸運六或其他旁注；不能因參考條目包含旁注就自行加入。
- 佣金逐局結算直接扣除是待整理的實作提案，非另外累積欠款；金額精度與取整待定。例如 $1 莊注獲勝，理論淨贏 $0.95，不能默認把佣金捨去。

## 已確認下注方式與節奏（第 52 題 A、第 53 題 A）

- 每局只選莊／閒／和其中一項下注，不能同時押兩個或三個項目。
- 下注總額不超過可用資金，最低下注遵守共通 $1。
- 下注倒數 30 秒，可提早按發牌；時間到鎖定投注並發牌。
- 超時未下注時跳過本局並重新倒數，不扣籌碼，已用道具照消耗。
- 思考與實際播放時間計入通關時間，暫停／背景處理遵守已定共通原則。

## 已確認道具（第 54 題自訂答案）

沿用共通道具方向：僅玩家使用、每局最多一件、一次性、無免費配給、每件購買前資金 10%，回地圖商店購買。

| 道具 | 已確認效果與時機 |
| --- | --- |
| 保本券 | 發牌前使用；本局若淨虧損，退回虧損的 50% |
| 透視鏡 | 已下注但尚未鎖注時，選莊或閒查看該方其中一張牌的點數；看完仍可於 30 秒期限內修改金額或改押莊／閒／和，保持單項下注（第 56 題 A） |
| 換牌券 | 鎖定投注前先啟用；首四張牌揭示後，選其中一張換成下一張牌，再重新按天牌及標準補牌規則處理 |

- 道具啟用即扣除。
- 換牌券啟用後，在首四張揭示時有 10 秒選擇替換哪張或保留原牌；超時保留原牌，道具不退。選擇時間照計通關時間。
- 換掉的原牌進棄牌區，不重新放回牌靴；最多換一次。先完成換牌選擇，才依最終初始牌面判定天牌及執行標準補牌。
- 換牌流程為遊戲自訂道具效果，不是指定維基百科的普通補牌規則。
- 透視結果必須對應實際要發的牌；不因後續操作重抽或更改已揭露點數。具體選牌方式後續整理，不再默認只看第一張。

## 已確認牌靴（第 55 題 A）

八副牌洗好後連續使用，已發或換掉的牌不放回牌靴，至切牌位置再重洗。切牌位置與燒牌等細節列待調校。

## 已確認透視後改注（第 56 題 A）

透視可在已下注、尚未鎖注時使用；看完可在原本 30 秒下注時限內修改金額或改押莊／閒／和，仍只押一項。使用透視不默認重置或延長倒數。啟用即扣除一件道具，占用本局唯一道具額度；原牌序與已揭露資訊保持一致。

## 其他待規劃／待調校

- 八副牌、發牌／補牌、三款道具效果、透視後改注及連續牌靴已定；不需重問。
- 透視選牌方式、切牌與燒牌細節、道具效果／價格的平衡未驗證。
- 單項投注、佣金及補償結算順序、完成一局後保存。
- 暫停、離線、速度選擇與共通框架的銜接。
