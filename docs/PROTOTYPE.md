# 原型0.1：B大廳＋大小

使用者已要求按「原型與貼圖分批同步」建議執行。流程為姓名／模式→故事卡→B大廳→大小下注→開骰／道具→結算→保存／下一局。五款遊戲的正式首版範圍不變，原型其餘四桌明示開發中。本輪無部署、帳號、支付、後端或新增樓梯玩法。

目前是原型候選，瀏覽器驗證受環境限制，尚未通過完整runtime gate。

## 實作所有權

- rules.mjs：50種投注、賠率、整數美分、crypto均勻骰子。
- game.mjs：權威資金、道具、階段、兩種倒數、通關計時、完成存檔快照。
- storage.mjs：schema1驗證、模式槽位、寫入前舊原始存檔備份；壞檔不自動刪除。
- app.mjs／styles.css：標準button操作、暫停遮桌、背景事件、匯入／匯出、自適應配置。
- scripts/package.mjs：不改圖片，將來源與五個PNG各嵌入一次，輸出無外部依賴HTML。

## 明示原型預設

以下是工程預設，未當作使用者已逐項確認的永久規則：

- 金額採整數美分；道具價格四捨五入至美分、最少1美分，保本遇半美分向下取整。派彩與保本完成後才判定勝敗。
- $0.01時購物可能花光資金而失敗；是否阻止花光或更改最低價仍待決定。不足$1可全押的規則保持。
- 第一局完成前沒有初始持久存檔；購物不立即保存，下一局完成後一起記錄。關閉／重整回最後完成局。
- 匯出只輸出最後完成快照。匯入在主頁或大廳存檔視窗執行，必須與選擇模式一致。允許本機重試，不宣稱競速防作弊。
- 自由模式有自動槽及一個手動槽；競速只有自動槽。手動保存按鈕在完成局顯示。
- 商店只有大小三款道具、各自暫定存量。跨五款背包容量與共用方式仍未定。
- 故事卡文案是草稿，不增加達標捐款結尾；開骰揭曉0.9秒，其他動畫後補。
- 地圖、思考、揭曉、重擲選擇都計時；商店、明確暫停停止。背景／失焦暫停，回來須按繼續。
- 無下注超時跳過，已用道具不退；有下注／已用道具的未完成局先完成再離桌。
- 桌面版地圖錨點入座；手機窄版在地圖下方列出大按鈕，方向尚待定案。
