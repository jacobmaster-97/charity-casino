# 0.1.8：牌桌整屏配置與移除咪牌手圖

使用者最新要求：「修整畫面至不用下拉也可以看到全部」，其後追加「刪除咪牌時的手部貼圖」。兩項一起處理，範圍是目前大小、百家樂及咪牌的主要遊玩畫面，不重設遊戲規則或存檔。

## 根因與修正

舊版每塊各自按內容撐高：手機HUD換兩行、上方牌局／骰盅最低高度、投注SVG按寬度推算高度、籌碼／自訂／操作逐列堆疊、次要details展開會再增加頁面高度。即使素材路徑正確，底部控制也會落到畫面外。本次不歸因於圖片解碼。

- 牌桌容器使用當前可用視窗高度，HUD單行、保留資金與時間；牌局在上、完整盤面及控制在下。visualViewport resize與window resize更新高度，CSS保留svh／dvh後備，不用整頁transform縮小。
- 中間盤面分配剩餘高度；SVG按原viewBox等比例完整容納，保留全部50種大小及6種百家樂投注區。主注／旁注及飛入籌碼仍用同一幾何；百家樂標籤及賠率加大，調整籌碼尺寸及錨點避免覆蓋文字。
- 五色籌碼、所選碼值、自訂、全押、發牌／開骰、清除留在底部。選中額可從籌碼文字及自訂框查看；重複的資金顯示移除，資金仍在HUD，下注總額仍在控制列。籌碼完整金額仍保留於aria-label／title；沒有刪除下注功能。
- 明細／移除、道具、精準選格／牌靴改為原內容的原生dialog，開啟不推高牌桌，按返回牌桌或Escape關閉並恢復焦點。既有控制節點移入dialog，事件仍交由app與Game處理。開啟時不額外暫停計時；真正暫停／背景時關閉dialog再遮桌，防止原生頂層蓋住暫停畫面。
- 大小放大盤面仍可主動開啟，在盤面區內查看細格；完整總覽是預設。次要dialog可有自身捲動，不把說明與明細全部常駐在主畫面。
- 窄版將自訂與主要操作並排，短橫向整合HUD／導航、牌局及底部列；主要按鈕維持44px級，長內容用情境面板，避免縮成難按的小字。
- 咪牌面板採有界網格，卡牌佔剩餘空間，直接揭牌／暫停保留；短橫向牌面和控制並排。刪除手圖繪製、單檔內嵌與根目錄／docs發布PNG；原生成檔僅留於歷史預覽。hand-assets.json標記停用，沒有新生成或編修圖片。彎角、慢速發牌、手動進度、放手保留、鍵盤／直接揭牌、暫停與結算不改。

## 檔案與證據

src/table-layout.mjs管理次要面板及視窗高度；app.mjs接線及table-shell；styles.css集中0.1.8有界配置；baccarat-squeeze.mjs移除手圖；board.mjs改可讀字體及籌碼錨點。package/pages腳本包含10張原PNG與10個runtime檔，生成Pages時明確移除舊手圖以免殘留。

94項檢查通過：22大小／保存、9盤面／籌碼、23百家樂、12旁注、12咪牌、7面板／視窗高度、3封裝、6Pages。新增7項驗證dialog開關／恢復焦點、重新render續用新控制、暫停／咪牌阻止重開、取消、階段移除控制及計時所有權；DOM替身不是瀏覽器證據。原4,000局資金模擬及咪牌流程繼續通過。封裝驗證10圖原位元組一致且不含手圖。

browser_smoke.py新增主牌桌垂直溢出及底部按鈕邊界檢查，涵蓋720×1280、1080×2400、390×844、320×568、844×390、768×1024及1024×768。腳本只通過Python語法，未在此環境啟動瀏覽器。既有Chromium IPC限制仍有效，不重複相同失敗路線。

## UI檢查與限制

P1：實際Safari工具列、鍵盤、旋轉、dialog及觸控尚待回測；極矮視窗內完整總覽仍可能較小，不能只靠CSS容器不溢出宣稱可讀性通過。精準選格及主動放大保留，瀏覽器字體放大亦需檢查。已移除重複常駐說明及展開式推高布局，body／主要控制字體維持14–18px級，原生dialog內說明16px。焦點以原生dialog約束，返回原觸發項。

720×1280、1080×2400、390×844、320×568、844×390、768×1024、1024×768、實體六吋手機及Safari皆UNVERIFIED；CSS與模板檢查不能當作裝置驗證。遊戲只支援繁體中文；留存／商店評分未測量。

UI Score：Readable／UX／Accessibility／Commercial／Retention／Google Play Risk皆未評分，缺瀏覽器／實機證據。Priority：P0主操作越界需裝置證據；P1Safari／橫直向／鍵盤；P2細格與觸控；P3盤面字體及錨點；P4保留已確認咪牌節奏。
