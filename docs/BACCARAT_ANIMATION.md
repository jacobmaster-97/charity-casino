# 百家樂0.1.7：慢速發牌與咪牌

使用者在2026-10-30明確指示「實裝動畫」，批准先前docs/previews/baccarat-squeeze-v1的拖動牌角預覽。階段為既有可玩原型的動畫整合與發布；不加入新桌或修改派彩。

## 實際行為

- 發牌及自動補牌速度為原來70%，每張400÷0.7＝571.4286ms，非只增加30%時長；牌面進場CSS同步。首四張順序仍閒、莊、閒、莊。
- 所押主注莊／閒需補牌時，該方第三張蓋牌送到放大的咪牌區。幸運六亦關聯莊方補牌；是否提供咪牌不預先透露莊6或勝負。只押對子或和注時自動補牌；天牌或不需補牌不顯示咪牌。
- 兩方均有關聯投注且均需補牌時，先完成閒方，才處理莊方，不能越序揭示。保留六區盤面、大額五色籌碼、主注單項及旁注複選。
- 按住牌面向左上拖動，牌角彎起、原預覽手圖跟隨，牌面逐步露出。放開／取消觸控保留進度，不倒退；再次拖動續揭。只接受主要指標，忽略其他手指。
- 拖至完成或按「直接揭牌」、Enter／空白後，700ms攤開、700ms歸位，再執行下一補牌／最終結算。方向鍵可逐步揭開。偏好減少動態時停用自主位移／翻轉及手圖，保留揭牌選擇與相同流程時間。
- 咪牌等待與操作照計有效遊玩時間，沒有另加超時；直接揭牌避免強制拖曳。暫停、背景／失焦遮桌及停表；按繼續恢復原進度、原牌序與剩餘動畫時間。
- 換牌券仍先在首四張後處理10秒換牌／保留，之後才判補牌。所有投注鎖注後禁止加注；不能提前結算，歸位後只結算一次。保存仍只完成局，schema1與原槽名不變。

## 工程及素材

Game擁有delivering→squeezing→unfolding→returning狀態、進度及剩餘時間；baccarat-squeeze.mjs只負責實際牌靴卡牌呈現、SVG彎角、主要指標／鍵盤輸入。穩定外層SVG保留pointer capture，僅重畫子圖層；requestAnimationFrame透過共用advance計時，不另累積第二個遊戲時鐘。動畫不抽牌，也不消耗新道具。

public/art/baccarat-b/hand.png是已批准預覽的生成右手原檔，未改像素，SHA及來源見hand-assets.json。牌面、枱布及籌碼繼續原PNG。根目錄／docs兩種Pages與單檔HTML均包含新模組及第11張PNG；預覽GIF／影片不隨網站發布。
