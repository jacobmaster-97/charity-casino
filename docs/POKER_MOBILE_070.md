# 0.7.0 德州手機橫向圍桌版

2026-11-02；階段：已批准介面的實裝／發布。使用者「可實裝畫面」批准先前v2無頭像預覽，取代此前只預覽的限制。

## 玩家會看到

- 橫向手機以六人圍桌呈現：上方三名、左右各一名對手，中央五張公共牌位置及彩池，自己的兩張手牌靠下。不用角色圖片、人物字母徽章；D／SB／BB只表示位置。
- 底部更多／棄牌／過牌或跟注／加注／全押。加注開原生臨時面板，輸入的是本輪加注後總額，五色籌碼只設定快捷金額，確認才投注；取消不扣款。窄屏跟注文字與金額分兩行，全押金額保留在資金欄及無障礙標籤。
- 開局、AI輪候、道具選擇及完成局有對應控制；更多保留彩池／紀錄、道具、速度及玩法。自己的剩餘秒數在手牌旁，面板亦顯示同步倒數。
- 頂欄沿用35.2px的已指定高度，其他主要按鍵至少44px。一般桌面、直向手機及一般平板保留既有德州排版。
- 低於360px高時，對手卡牌與投注合併到姓名框內，避免壓住中央公共牌；加注面板受可視高度限制並可捲動，供軟鍵盤出現時使用。

## 實作與契約

`src/poker-view.mjs`的mobile分支沿用原卡牌、籌碼renderer與13個飛行目標。`src/table-layout.mjs`的mobilePokerViewport以layout viewport選擇寬大於高、寬≤1100且高≤600的模式；不以visualViewport鍵盤高度作模式切換依據。`src/app.mjs`同時追蹤原三桌與德州profile，所以667×375轉375×667亦重排；Game及本局物件不重建。

加注面板沿用TablePanels搬移原details到native dialog，沒有第二個下注／計時擁有者。各下注與道具按鍵帶現有turnId；換回合清掉暫存選牌、加注值及面板選擇，防止舊面板在後一回合重開。關閉面板回焦加注鍵。面板不暫停；明確暫停／背景仍走既有Game暫停與遮罩。

六人無限注、AI、盲注、30秒超時、短碼重開權、邊池、唯一派彩、正常／快速、600ms收注、音效及保存schema1保持原owner。仍只在完成手保存。電腦勝出仍只金框，不增加勝出牌型或人物圖示。五色籌碼外圈及0.6.3深藍／冰白面額、亮青合計延續；沒有更換PNG。

## UI閱讀審核（程式／已批准預覽層，非實機）

可讀性暫評3/5：姓名16px、資金／輔助14px、主動作18px，窄屏跟注16px分兩行；小對手牌仍需實機判讀。焦點排序：自己的決策與手牌★★★★★、公共牌／彩池★★★★☆、對手行動★★★☆☆；紀錄、速度、道具與加注快捷值收起，常駐資訊沒有增設新系統。觸控主列44px；35.2px頂欄是使用者指定例外。金框附ARIA得主標籤，行動另有倒數／文字；籌碼與盤面分色延續。長金額的對手投注可截斷，但更多保留完整值；自己的跟注額分行。

首30秒：✔開始／主要動作可見、✔目前彩池與自己資金、✔合法操作由Game決定、✔更多提供玩法／購物需完成手離桌；△真正觸控回饋待驗。30秒續玩意願暫評3/5，僅設計判斷；可見發牌及對手節奏保留，尚無使用者研究。介面投訴風險粗估30%（非商店評分預測）：主要未驗的小對手牌、極短高度及鍵盤，必須以Safari實機複核，不能用本估計替代測試。只支援繁體中文，未新增其他語系承諾。
