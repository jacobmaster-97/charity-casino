# 0.10.1 · 21點手機橫向介面修復

階段：維護／介面修復。使用者截圖顯示「21點」與返回／玩法按鈕拆行，玩家手牌只剩一小截。目標是在手機橫向單屏清楚看見莊家／自己手牌及五項操作，不改規則、派彩、計時、存檔或12張原貼圖。

## 原因與修正

原21點沒有加入手機單行HUD，沿用短螢幕舊導航。牌桌再把35%高度給莊家，其餘65%同時容納玩家標題、手牌、54px籌碼列及底部操作／工具，導致手牌彈性區可被壓至幾像素。卡片強制最少24px寬也無法修復分配不足。

- 手機橫向獨立判斷：layout viewport寬大於高、寬≤1100、高≤600、數值有效；不受德州手機版開關影響。旋轉只重排，保留現局／籌碼／道具／餘秒。
- 使用既有縮矮20%的35.2px頂欄，整合返回、21點、資金、挑戰倒數、行動倒數、更多及暫停，只有一個countdown。
- 深綠金邊桌布保持。莊家左側、玩家右側，兩者共享剩餘高度；操作在獨立底列。所有分牌保持單行各有手牌／狀態／下注，隔離舊直向「只顯示當前手」CSS。
- 投注明細、道具、牌靴及玩法放原生dialog的更多，沿用TablePanels。沒有新增常駐資訊／網絡載入門檻，工具開啟仍計時，手動／背景暫停規則不變。
- 下注籌碼區壓至30px，主操作至少44px／18px字；頂欄35.2px是既有使用者20%縮矮規格的例外。非互動牌按實際容器高度fit；換牌的每張牌至少44px寬，長手牌在牌列內滑動、無重疊點擊區。
- 桌面與直向沿用原版。Game／blackjack engine、保存及資產不改。升版0.10.1讓Pages模組與CSS一起刷新。

## 驗證及限制

`npm run verify`：336規則／元件／接線檢查、3單檔封裝通過；`npm run prepare:github`：6 Pages檢查，總345。保留原五款遊戲、500五分鐘挑戰及10,000局回歸。新增5項覆蓋斷點、保險／各階段DOM、旋轉不改局／雙時鐘、長手牌獨立點選與短容器fit。測試事件替身原來覆蓋較早resize handler，改為累積事件後驗證真實兩個監聽器。

`tests/browser_smoke.py`新增橫向手牌實際邊界／至少60px高度、單一倒數、隱藏底工具與44px操作檢查，僅Python編譯，未執行。未重試已知HTTP／Chromium IPC限制。Node／DOM替身不能證明Safari實際CSS或觸控。

待iPhone16Plus實機：橫向含Safari工具列展開／收起，查看兩張至長手牌、1–4手分牌、換牌滑動／點擊、保險、工具往返、暫停／背景／旋轉，確認牌面／籌碼／倒數及五鍵無遮擋、整頁不需捲動。iPad／桌面／直向也須視覺回歸；原生PNG分享未另實機驗證。
