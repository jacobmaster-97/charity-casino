## 已確認盤型（第 66 題 B）

- 美式雙零：0、00、1–36 共 38 格。
- 0 與 00 為不同格、皆為綠色，不屬紅／黑、單／雙、1–18／19–36；上述等額投注遇零全輸，沒有半退或押注留置特例。
- 號碼排列、紅黑映射與零附近的相鄰下注幾何需按美式盤型整理，不能混用歐式輪序。

## 已確認下注節奏（第 68 題 B）

下注倒數 30 秒，可提早啟動；超時鎖定有效下注並轉輪盤。超時未下注時跳過本局、重新倒數，不扣籌碼，已用道具照消耗（第73題A）；不套用21點的20秒。

## 已確認賠率（第 70 題 A，套用第 69 題 B 已開放種類）

命中另退該注本金，未命中損失該注本金。原先完整賠率表的邊線投注未啟用，不因第70題採用賠率而加入。

| 投注 | 淨贏賠率 |
| --- | --- |
| 單號（含 0、00） | 35:1 |
| 十二數組／直列 | 2:1 |
| 紅黑／單雙／大小 | 1:1 |

## 已確認同局下注（第 71 題 A）

同局可下注多項，各注獨立結算，總下注額不超過目前資金；最低 $1 與最多全部資金遵守共通原則。

## 已確認道具（第 72 題 A）

僅玩家、每局最多一件、一次性、啟用即扣、無免費配給，每件購買前資金 10%，回地圖商店購買。

| 道具 | 效果與使用時機 |
| --- | --- |
| 保本券 | 啟動輪盤前使用，本局全部投注合計若淨虧損，退回虧損的 50% |
| 透視鏡 | 下注鎖定前，排除五個本局不會開出的單號（0、00 也在可排除範圍），玩家可據此調整下注 |
| 重轉券 | 下注鎖定前先啟用；開獎後有 10 秒選擇重新轉一次或接受原結果；超時接受原結果，道具不退 |

- 透視需先固定本局實際結果，從其餘37個號碼中選五個排除，改下注不可重抽結果；不是直接預告必中單號、紅黑或大小。
- 重轉只允許一次，從完整38格重新抽結果，可與第一次相同；全局所有投注按最終結果結算，已鎖投注不能更改。
- 重轉券在鎖注前啟用即扣；重轉、主動接受、超時接受均不退券。僅持有但未啟用，不自動進入道具倒數或扣券。
- 透視與重轉不能同局疊加，遵守每局一件；不要沿用骰寶持券即顯示選擇分支的方案而未告知。
- 排除五號及道具定價已獲採用，但資訊價值與整體平衡尚未驗證。
