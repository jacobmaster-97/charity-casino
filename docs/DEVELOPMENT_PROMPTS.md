## 提示詞一：本機五分鐘挑戰

```text
請在 /workspace/web-game 開發《賭王慈善大賽》的本機五分鐘挑戰。

開始先讀 AGENTS.md、CODEX_HANDOFF.md、DEBUG_HANDOFF.md、docs/GAME_BRIEF.md、docs/FIVE_MINUTE_LEADERBOARD_PLAN.md 及 .agents/skills/gamestudio/SKILL.md。使用繁體中文溝通，沿現有結構開發。

本階段只處理本機遊戲，先不串接Cloudflare、Supabase或其他網絡排行榜，不建立雲端資源，不上傳玩家資料。本機完成與驗收前，不開始提示詞二。

已確認規則：
1. 每次新挑戰由$100開始，五分鐘有效遊玩時間內以最終資金最高為目標。移除$25,000,000通關條件；資金超過該值仍可繼續。
2. 購物、大廳、下注、思考及正常動畫都計入五分鐘。手動按暫停或切到瀏覽器／裝置背景時，總倒數、行動倒數與牌局一起暫停，遮住牌桌並禁止操作；回來後按繼續，保留原局、籌碼、已用道具及餘秒，不重設。
3. 五分鐘到時立即停止接受新投注及玩家決策，不開新局。有投注的局自動依既有超時／預設規則收尾，再計最終金額；無投注則直接結束。收尾不提供額外玩家思考或加注機會，不重抽、不重複派彩。先列清五桌的精確收尾轉移，再實作。
4. 結算後資金歸零可提早結束。全押後可用資金0但仍有未結算投注，不立即判破產。
5. 保留大小、百家樂、21點、德州撲克、輪盤的既有玩法、賠率、道具、已確認介面、貼圖、籌碼／發牌動畫及聲效，不自行新增玩法限制或強制統一快慢設定。
6. 結算顯示名稱、最終金額、淨利、完成局數及結束原因。之後給排行榜的遊戲資料只有名稱與最終金額；本階段只準備本機結算結果，不發送網絡請求。
7. 保留舊存檔並區分新挑戰資料，不把舊版資金／道具帶入新的$100挑戰。延續只在完成局保存的原則；恢復同一新挑戰應保留已存剩餘時間，不能補滿五分鐘。明確處理版本及金額精度，不靜默刪檔或溢位，不把技術限制誤當新的通關上限。
8. 手機橫向、平板及電腦保持合適比例；主要遊戲畫面不需整頁上下捲動。保留目前無頭像德州、牌型提示及公共牌間距。

驗證五分鐘邊界、購物照計、手動／背景暫停與恢復、到時未完局、全押、唯一派彩、破產、保存恢復及五桌回歸；同步檢查單檔與Pages封裝。只回報實際執行的結果；瀏覽器／Safari未測要明示，遵守DEBUG_HANDOFF既有失敗路徑的停止重試限制。

交付可玩的本機版本、相關驗證及更新後的交接文件，列清仍待定的細項。完成本階段後停止，不自行接入排行榜。是否更新既有GitHub Pages，依執行時的任務授權處理；不另行啟用雲端或付費服務。
```

## 提示詞二：Cloudflare精簡排行榜（本機版本完成後才使用）

```text
本機五分鐘挑戰完成及驗收後，才開始本任務；若尚未完成，先列清缺項並回到本機開發，不以舊0.7.1視為已具備新玩法。

在 /workspace/web-game 為《賭王慈善大賽》加入Cloudflare Workers＋D1網絡排行榜，保留現有GitHub Pages遊戲。先讀 AGENTS.md、CODEX_HANDOFF.md、DEBUG_HANDOFF.md、docs/GAME_BRIEF.md、docs/FIVE_MINUTE_LEADERBOARD_PLAN.md、docs/LEADERBOARD_ANTICHEAT_OPTIONS.md 及gamestudio技能。

已選方案：只上傳名稱與最終金額，接受基本防護。五分鐘計時、下注、亂數、暫停與派彩均留在本機；不要改為伺服器遊戲、建立短暫牌局驗證，或收集永久／暫時的下注流水。舊文件中的全程後端方案已未選用，不需再次要求用戶接受它。

功能：
1. 玩家完成一場有效本機挑戰並結算後，才可按「上傳排行榜」送出結果。遊玩中不發計時、下注或派彩同步請求。
2. 雲端只接收名稱與最終金額這兩項遊戲資料；可使用必要的提交技術ID防止同一完場因重試重複入榜，不另外收集牌局／行動／道具資料，也不要求玩家註冊帳號。
3. Worker驗證欄位型別、名稱長度、金額非負及精確表示、請求大小，使用參數化SQL、安全文字顯示、合理限流及冪等提交。不得自行設定未確認的遊戲金額封頂，或把少見但合法的高額成績直接判作弊。
4. D1保存排行榜；查詢按最終金額由高到低，遊戲內供所有玩家查看名稱及金額。使用索引、合理分頁及快取控制讀取量，不讓排行榜長列表撐長整個遊戲頁面。
5. 顯示上傳中、成功、失敗及可重試；失敗不能清除本機結算，也不能迫使玩家重玩。重試同一結果不新增重複紀錄。
6. 名稱不是唯一身分，不因同名就覆蓋別人資料。每個匿名身分保留最佳或每次完成各留一筆尚未定案，先釐清此項資料規則；不把單次提交去重誤稱為已防止一人多次遊玩或多身分。
7. 明確承認這是裝置報分及基本防護，不能宣稱已驗證完整遊玩或杜絕改分。不重新推銷用戶已未選用的完整伺服器驗證。

先做可檢查的Worker程式、D1結構／索引、上傳與查榜API、前端整合及本機測試。Cloudflare金鑰只放部署環境，不放HTML或公開GitHub；缺少帳戶或設定時只詢問必要資訊，先完成不依賴帳戶的工作。

依實作時最新官方文件核對免費額度及估計每日請求／讀寫；每次完成只留一筆排名不代表API或索引寫入恰好一次。不要把估算當負載測試，也不要自行啟用付費方案。

驗證非法名稱、錯誤金額／溢位、注入與安全顯示、限流、重試去重、同名、排序／分頁、上傳失敗重試及手機介面。實際部署與公網測試完成才可宣稱所有玩家可用；尚未部署或未驗證需明示。

更新交接、API及部署文件；本機玩法、計時及已完成的遊戲效果保持。只有完成本機前置任務及本任務授權範圍內，才進行相應發布。
```
