# 美式輪盤可玩切片0.4.0

使用者要求「下一步開發」，依ROULETTE.md已確認第66–73題接入第五桌；五款原型均可從大廳入座。這是原型可玩發布，不宣稱Safari、觸控或平衡通過。

## 玩家流程與規則

入座 → 30秒選五色／自訂／全押籌碼、點獨立投注格（或精準選單）→ 可先用一件道具 → 鎖注並轉動4.8秒 → 若已啟用重轉券，首次揭示後有10秒接受或重轉一次 → 全部原注按最終結果一次結算、判達標／歸零及保存 → 再玩或離桌購物。

美式0、00、1–36共38格，兩種零號分開且為綠色。順時針輪序：0,28,9,26,30,11,7,20,32,17,5,22,34,15,3,24,36,13,1,00,27,10,25,29,12,8,19,31,18,6,21,33,16,4,23,35,14,2。0與00相隔19格，沒有混用歐式單零輪序。紅數為1,3,5,7,9,12,14,16,18,19,21,23,25,27,30,32,34,36，黑數為其餘1–36。

獨立投注共50格：38單號、3十二數組、3直列、6外圍（紅／黑、單／雙、1–18／19–36）。淨賠分別35:1、2:1、2:1、1:1，中獎另退該注本金；0及00不屬任何六種外圍，也不屬十二數／直列。每格可以累加、多項同押，合計不超資金。一般每次至少$1；總資金不足$1可全押。沒有邊線、交點、兩號、三號、四號、六號或首五數，點邊界仍只認獨立格。

## 道具與資金

背包與其他桌共用，沒有免費配給，購買前資金10%定價不變，整局最多一件。保本、透視及reroll可用；swap不可用。reroll沿既有大小重擲庫存，商店標示「重擲／重轉券」，輪盤桌內顯示「重轉券」，沒有新增存檔道具ID或送券。

- 保本：鎖注前啟用即扣；最後全部投注合計淨虧損退50%，不足一美分向下取整，只退一次。
- 透視：入座時固定本局結果，從其餘37號無放回抽五個排除，0及00也可能被排除。原30秒內可調注，不重抽結果、不重設倒數、不自行刪除原本投注；格子以虛線及刪線標記，仍可選注。
- 重轉：必須鎖注前先啟用即扣。首次轉完有10秒接受原結果或重新轉一次，超時接受；三者均不退券。僅持有不自動顯示決策。重轉從完整38號等機率抽取，可與原結果相同，不可再轉第二次，所有原注按最終結果結算，鎖注後不能加注。

金額全為整數美分；下注先預留、鎖注立即扣款，未結算派彩不能使用。保本退回後才判目標或破產，暫時全押零餘額不提前Game Over。空注超時跳過重開30秒，不發牌、不扣籌碼、不checkpoint，已用道具不退。

## 真實盤面與動畫

沿B翠綠PNG枱布、酒紅／暖金框及既有五色籌碼。輪盤、輪序數字、金邊與木紋漸層、小球及投注格為本專案原創SVG程式繪製，直接用於正式遊戲，沒有外部圖片或臨時示意圖；沒有新增手圖或PNG。既有10張PNG位元組不改，來源見原素材assets.json與PROTOTYPE_ART.md。

上方展示轉輪及結果，下方完整盤面與底部控制。寬版數字12×3，左00／0，右三列2:1，下三十二數組及六外圍；窄高版數字3×12，頂部0／00、兩側十二數及外圍、底部三直列，投注集合不變。rouletteCells同時產出印刷及HTML籌碼定位資料。放大是玩家主動操作，預設完整總覽；小格另有原生面板50項精準選單及44px下注按鈕。五色面額隨起手資金提升，自訂與合法全押沿用。

ChipFlights使用實際DOM落點，600ms弧線及混色堆疊，各格金額同步，透明籌碼層不攔截投注。開出的單號及已派彩投注有框色，透視排除有虛線／刪線及輔助閱讀文字。重排、縮放、重畫不改投注或結果。

輪盤與球反方向多圈減速，結束角度由同一ROULETTE_WHEEL索引計算；ballTo−wheelTo的餘角準確對應最終號碼，重轉沿上次結束位置繼續。Game保留spin的from／to、4800ms及remaining，視圖用負animation-delay及play-state恢復同一進度，沒有第二個財務／遊戲時鐘。暫停／背景遮桌一起停，返回按繼續；減少動態偏好顯示最終靜態位置但下注仍鎖定，計時仍走原轉動長度。

## 所有者、保存與回復

Game仍唯一錢包／庫存／時鐘／checkpoint。roulette.mjs處理純投注集合、紅黑、輪序、固定結果／排除、派彩與角度／盤面幾何；roulette-game.mjs方法接Game；roulette-view.mjs提供實際SVG、控制與籌碼層。randomBelow沿既有拒絕取樣，不用Math.random模除作抽獎。新輪盤結果一局固定，只有合法重轉才重抽。

下注／道具按鈕帶round id；點擊前advance若已空注超時重開一局，拒絕舊按鈕，避免把舊透視資訊的選擇用到新結果。引擎亦驗證預期round id、階段、金額、庫存與暫停。

schema1與原槽保持，輪盤不需新增持久欄位；完成局攜帶兩副牌靴、AI桌面與背包。原pokerTable、blackjackShoe、baccaratShoe及舊缺欄位保存仍有效。只存最終完成局；重轉決策／動畫未完成都不保存。完全關閉或重整回最後完成局，當前未完成輪盤作廢；暫停但頁面存活則保持原結果、動畫、已用道具及剩餘秒數。
