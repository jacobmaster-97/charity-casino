# 0.6.2 大小／輪盤盤面文字固定

2026-11-01使用者提供輪盤截圖，要求大小／輪盤的盤面文字不因放籌碼而移動。屬介面修整，直接實裝，無需再預覽確認。

## 根因與修改

- 輪盤原`.rou-cell.has-bet .rou-cell-copy`使用`translateX(var(--rou-text-shift))`把數字及賠率向左移22%格寬，下注高亮變化時套入，150ms過渡使移位明顯。移除這條下注後位移規則與模板未再使用的`--rou-text-shift`。
- `.rou-cell-copy`明確`transform:none;transition:none`，50格的SVG x/y、文字錨點及盤面幾何不改，手機／平板／桌面及放大版皆生效。
- 大小沒有找到同類讓位邏輯，原本是固定SVG文字、籌碼另層。加上僅針對`.sicbo-screen .printed-cell>text`的不位移／不過渡樣式，保留既有位置；不更動畫骰圖的幾何transform。
- 高亮`has-bet`仍保留供投注格／輔助閱讀，籌碼飛行、混色堆疊、金額、結果高亮及精準下注保持。
- 百家樂`.bet-copy`既有讓位不在本次要求內，不套用此變更。
- 規則、資金、保存、道具、音效、頂欄35.2px及小窗120%保持。快取版本同步0.6.2。

## 驗證與回退

沿用237項程式／規則／視圖／封裝／Pages檢查；不為可逆CSS刪除新增只比對實作字串的鏡像單元測試。browser_smoke.py補實際SVG文字getBoundingClientRect，在大小兩次下注及輪盤精準下注後等飛籌碼完成，逐一比較文字內容、位置與尺寸，捕捉CSS移位而不是只比對x/y屬性。此腳本僅Python語法檢查，未執行瀏覽器，既有HTTP／Chromium IPC停用限制維持，Safari實機仍UNVERIFIED。

回退只需復原兩個顯示檔並更新快取／封裝；前版main7609a9725dccc5569ba38e65d3d11b5c4c2e7b03。沒有資料遷移或刪玩家進度。
