# 百家樂可玩原型0.1.5

本次接續大小0.1.4，完成第二張可玩賭桌；德州撲克、21點及輪盤仍是開發中入口。維持B港式賭片美術、上方牌局／下方完整投注盤面、底部操作、五色籌碼及原有大小玩法。

## 可玩流程與既定規則

大廳點百家樂→30秒下注→閒／和／莊單項投注→鎖注發牌→按標準規則補牌（或已啟用換牌後選擇）→結算與完成局保存→再玩／離桌。

八副416張牌，牌值A=1、10/J/Q/K=0、合計取個位；天牌8／9優先。無天牌時閒0–5補牌，再按閒是否補牌及其第三張點值決定莊補牌。莊0.95:1、閒1:1、和8:1，命中另退本金；和局莊／閒退本金。全押仍等結算後才判斷破產／勝利。

同一區再次點擊增加所選金額；點另一區把整筆原注移過去，不額外加碼。此操作規則在盤面上方說明，防止單項投注變成多項或改押時重複扣款。可清除、移除單項、自訂及低於$1時全押。

## 道具與舊版的差異

保本券及透視鏡沿用共用存量；重擲券僅大小可用；新增獨立swap存量的換牌券，每次在商店花購買前資金10%，開局不贈送。

- 保本券：鎖注前用，本局淨虧損退50%，以整數美分向下取整。
- 透視鏡：已下注、未鎖注時選莊或閒，隨機查看其中一張的百家樂點值，保留原倒數；牌序固定，仍可改注。只透露點數，不額外露出牌階或花色。
- 換牌券：鎖注前啟用即扣一件。四張初始牌揭示後10秒選一張換成下一張或保留。換出的原牌留在已消耗牌序／本局棄牌紀錄；按換後四張重判天牌及補牌。超時保留，不退券。持有而未啟用不自動進入分支。

每局最多用一件，不能疊加，也不回退已處理步驟。商店仍只在大廳開啟，購買隨下一完成局保存。

## 原型工程預設（非新增永久玩法確認）

- 全部使用整數美分。莊家勝注的淨贏款按下注×95/100向下取整到美分，逐局直接結算；佣金顯示為未扣前贏款與實得之差，不累積欠款。例如$1莊注淨贏$0.95，$1.01莊注淨贏$0.95。
- 用密碼學隨機整數作Fisher–Yates洗牌。新一局開始時若餘牌少於60張才重洗，手內不重洗；目前不另外模擬開靴燒牌儀式。
- 初四張先預留、鎖注才推進游標，供透視固定資訊。未下注超時跳過時將這四張視為棄置以更新下一局牌序，不扣錢、不計完成局、已用道具不退；不建立保存。空注且未用道具離桌則不消耗四張。
- 初始牌依閒莊閒莊每400ms揭一張，第三張每400ms依序揭示。動畫、思考與換牌選擇照計通關時間；暫停／背景遮桌與停表，繼續保持剩餘秒數與原牌。動畫是呈現層，發牌／結算由Game控制。

## 保存相容與所有權

Game共用資金、道具、計時與勝敗；src/baccarat.mjs持規則／洗牌／派彩純函式；src/baccarat-view.mjs持牌面和介面；src/board.mjs共用五色籌碼／飛行及盤面金額層。

仍使用schema1及既有競速／自由槽位，新增可選baccaratShoe={cards,cursor,cycle}及inventory.swap。讀舊檔缺swap時補0、不送券；沒有牌靴時在首次入座建立。匯入驗證416個唯一牌ID、游標、靴數，壞檔不覆蓋目前進度。完成局才記整副牌靴進度，換桌及Sic Bo完成保存也保留。完全關閉仍回最後完成局，不保存未完成牌面／下注／道具狀態。

新牌面及牌背為同一張原始RGBA PNG，1499×1049，來源與SHA見public/art/baccarat-b/assets.json；原圖完整複製，正背以明確SVG clipPath取格。52種牌階／花色為UI文字層，不能因隱藏牌的CSS類別或aria-label洩露花色。其餘直接重用已確認翠綠枱布、五色籌碼和道具圖。

每個投注區在小螢幕仍是三個大選項；底部控制換行，道具／明細／牌靴資訊可展開。換牌時四張牌各有至少44px互動寬度。新道具票券重用原道具圖示並標明「換牌券」。卡牌、籌碼、投注標記皆分層，不把整頁烘焙成圖片。
