# 本機五分鐘挑戰 0.8.0

2026-11-02（香港）；階段：本機可玩切片／封裝驗證。本次只實作使用者的第一階段，本機程式及單檔／Pages目錄更新，不接排行榜、不建立或部署Cloudflare／Supabase，不修改遠端GitHub Pages。

## 玩家流程

姓名／模式 → 故事卡 → 每次新挑戰$100、有效五分鐘 → 五桌遊玩或購物 → 五分鐘到自動收尾／結算後破產 → 本機結果。已移除網頁新挑戰的$25,000,000達標終止；超過仍繼續。

HUD改為剩餘時間，最後一秒以向上取整顯示，不因顯示而少給遊玩時間。大廳、商店、下注、思考、實際動畫都計時；購物畫面不再宣稱停錶。只有手動暫停或背景／失焦生命週期進入暫停；規則及存檔說明面板本身不會停錶。背景發生在說明面板開啟期間也會切成遮桌暫停；回前景仍需按繼續，保留原局、道具、總及行動餘秒。

現有聲效控制／短聲不補播／長聲恢復邏輯保留，暫停仍交原Game與聲效owner處理。

## 五分鐘截止

Game是唯一挑戰時鐘、資金、統計及保存owner。tick先按原牌局消耗該段時間，再檢查300000ms邊界；避免把截止前的時間扣到截止後新建的鎖注／發牌動畫。

到時進入closing，禁止玩家再下注、用道具或作決策，也不能開下一局。已提交的投注／牌局自動依現有規則結束，保留原來的搖骰、轉盤、發牌與收注等待；這段收尾不增加有效五分鐘。不重抽已決定結果。玩家仍可暫停收尾的展示，恢復後不獲新決策機會。

| 狀態／遊戲 | 截止後處理 |
| --- | --- |
| 大廳、商店、已結算牌桌、德州尚未開始 | 直接完成挑戰，不新增局數 |
| 沒有投注的下注階段 | 直接完成，不假開獎、不新增局數 |
| 已有投注但未鎖定 | 自動鎖注，再按原玩法收尾 |
| 大小重擲選擇 | 接受原骰；按既有規則消耗重擲券一次 |
| 百家樂換牌／咪牌 | 保留原首四張；補牌按標準規則，咪牌自動揭示 |
| 輪盤重轉選擇 | 接受原號碼，不多轉一次 |
| 21點保險／玩家行動 | 不買保險，所有待操作手停牌，莊家按S17完成 |
| 德州玩家行動 | 可過牌則過牌，否則棄牌；AI沿既有策略，牌局／收注／邊池照常完成 |

截止後只有Game內部自動轉移能通過輸入屏障。相同階段但不同分牌手也能向下一手推進。所有最終派彩及局數只執行一次；全押的可用0不先判破產，要等完整派彩／退款／邊池。挑戰結束後tick不再推進，不能再投注或購物。

## 本機統計及顯示

結果顯示姓名、最終資金、有效遊玩時間、總完成局數、道具購買支出，以及五桌各自的完成局數與淨贏取。

「贏取金額」以明確標示的淨贏取呈現：派彩＋保本退款－投注，可為負數。21點同次發牌的所有分牌／保險合計一局；德州一手合計一局。未下注跳過及未開始的德州不計局。購物支出不算任何桌的虧損，另列以核對：

最終資金＝100元＋五桌淨贏取合計－道具購買支出。

HUD以現有時間欄替換舊通關計時，不新增常駐資訊列。結算表與總額在有界面板；大額文字可換行，短屏可在面板內捲動，主要遊戲頁不靠整頁上下捲動。商店改有界卡片，購買控制保留，說明在卡片／次要說明內捲動。

## 金額精度

src/cash.mjs使用整數美分：一般值保持安全Number，超出安全整數後自動轉BigInt。投注、佣金／3:2／退款取整、德州AI買入／彩池／平分零頭、購物成本、統計、顯示與輸入都用精確運算，無新玩法金額封頂。AI機率使用有限精度的比例，不把它用於金錢結算。

輸入以decimal文字解析，不先經Number乘100；拒絕科學記號、NaN、Infinity及過多小數。大金額籌碼或價格用簡短標記，詳情／輸入／最終結果保留完整金額。極大金額輸入與匯入限制為資源保護，不是達標勝利條件。

JSON將超大整數寫成十進位字串，載入時還原；型別、統計與資金帳必須一致，不能靜默截斷。之後Cloudflare階段還需定API／儲存精度，不是本輪已完成的功能。

## 舊存檔與保存

網頁入口明確使用Game({challenge:true})；引擎保留legacy相容路徑供舊schema1回歸及驗證，不在新網頁入口開新舊25m挑戰。

新五分鐘為schema2／ruleset five-minute-v1，使用charity-casino-five-minute-v2的獨立auto／manual欄位。保留模式race／free的原自動／手動差異，但兩者均為五分鐘。新局不讀取舊資產；匯入schema1會說明不能帶入新挑戰，原資料不刪除。首頁若有同模式的舊存檔，可匯出保留。

一般只在完成局邊界保存，包含剩餘時間、五桌統計、購物支出、背包及原牌靴／德州桌。挑戰最終結束也會保存結果，即使未玩任何局；不做局中持久快照。頁面存活的暫停保留當前局，完全重整回最後已完成局，仍沿用使用者已接受的回溯邊界；載入不補滿300秒。最後收尾局直接保存finished紀錄一次，不先派彩／保存兩次。
