2026-11-02（香港）；本機第一階段0.8.0已實裝／封裝，詳LOCAL_FIVE_MINUTE_080.md；本排行榜部分仍是規劃，遠端正式0.7.1未改，未建立雲端。這一版取代先前Supabase全程伺服器方案作為目前決策入口。

## 使用者已確定的新目標

每次挑戰$100起步；五分鐘內以期末資金最高為目標；資金歸零提早結束；完場後可把遊玩成績公開到網絡排行榜，供所有玩家查看。這會取代舊$25,000,000通關／最快時間目標，並非增加另一個達標上限。五款玩法與既有美術先保留。

全押後可用餘額為0但尚有未結算投注，不立即判破產；要等該手所有派彩、退款／邊池完成，確定沒有資金才結束。

## 最新已確認細則（以使用者更正為準）

1. 五分鐘是300秒有效遊玩時間。購物及在賭場大廳／地圖時計時繼續；手動按「暫停」或切到瀏覽器／裝置背景時，凍結總倒數及本局行動倒數並禁止操作。回到前景後按「繼續」，保留原牌局及總／行動餘秒，不重設。這是使用者最新修正，取代先前對背景照計的解讀。
2. 時間到自動收尾已下注局，再計最終資金。停止接受新投注與玩家行動，21點停牌；德州玩家可過牌則過牌，否則棄牌，其他選擇依固定超時預設。各桌精確自動收尾／AI後續行動政策仍須在實作規格列清楚，不能另給玩家超過五分鐘的決策時間。
3. 第一版用暱稱＋匿名身分，免註冊。清除瀏覽資料或換裝置後無法自動找回同一身分，但先前已公開的成績仍保留；暱稱不是唯一帳號識別。日後可另加Email綁定。
4. 最新停錶條件為「手動暫停或切到背景」；購物照計取代原有商店停錶。不得自行加暫停次數／時長限制，亦不得將賭場大廳誤當瀏覽器背景。

尚待定案的工程／產品細節：排名局正常／快速動畫是否固定、每身分最佳或每次成績皆列、同分與日／週榜規則、金額上限及精度、每桌收尾的細項。本文件後續相關方案均為建議。有效五分鐘容許玩家暫停後思考，因此不是連續牆鐘五分鐘賽，榜名與說明須一致。

## 最新的資料範圍與防作弊需求

使用者指定原則：本機完成五分鐘後才上傳，Cloudflare最後只收名稱及最終金額，不長期收集下注、暫停或派彩紀錄；隨後亦要求攔截作弊產出的資料。

使用者已明確選擇「只上傳名稱金額，接受基本防護」。僅收到兩欄可做格式、安全顯示、限流與重試去重，但無法可靠驗證金額是否真的贏回。前述短暫狀態驗證不採用；不要擅自加全程後端、計時同步或牌局暫存。詳[LEADERBOARD_ANTICHEAT_OPTIONS.md](LEADERBOARD_ANTICHEAT_OPTIONS.md)。

## 精簡版本的服務分工

GitHub Pages保留遊戲；前端本機處理規則、計時、暫停及派彩；完場按上傳才送名稱與最終金額到Cloudflare Worker，由D1保存並依金額排序。其他玩家開榜時讀公開成績，不需要Supabase。前端不持有Cloudflare管理金鑰。

這是由裝置報分的榜，不應顯示「已驗證真實遊玩」。基本防護包括名稱／金額型別與精度、純文字顯示、參數化SQL、提交限流及同一次上傳重試去重；不是所有作弊都能攔截。遊玩中不發驗證／暫停同步／派彩紀錄請求。

名稱不是唯一身分；去重技術ID、每身分最佳／每局一筆、同分順序、日／週榜及金額精度仍要定案，不能只按同名覆寫。排行榜展示可只列名稱及金額，內部技術識別不等於公開遊玩流水。

## 原有遊戲改動範圍

新挑戰固定100元、300秒有效時間，移除25m達標終止；購物及大廳照計，手動／背景暫停保留總與行動餘秒，到時自動收尾已下注局。舊schema1資料不刪、不把舊資產帶入新挑戰。原金額上限、JS精度、排名速度及各桌收尾細項需另作規格；不因排行榜只留兩欄就忽略溢位。

## 已核對的容量參考（非實測）

Cloudflare免費Worker每日100000請求，每次CPU10ms；D1每日500萬列讀／10萬列寫，單庫500MB、帳戶總5GB且最多10庫。按每筆含索引平均1KB及20–30%餘量，單庫粗估35–40萬筆累積成績。讀寫上限另計，加入遊玩期間驗證後需重估。LootLocker免費Personal是每月10000活躍玩家，且有組織營收／融資資格；這不是總保存筆數上限，細項查其管理台。

來源：[Worker limits](https://developers.cloudflare.com/workers/platform/limits/)、[D1 limits](https://developers.cloudflare.com/d1/platform/limits/)、[D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/)、[LootLocker pricing](https://lootlocker.com/pricing/)。容量並非保證，未作負載測試。
